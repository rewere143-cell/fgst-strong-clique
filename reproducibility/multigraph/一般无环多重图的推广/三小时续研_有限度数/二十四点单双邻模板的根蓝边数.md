# 二十四点单双邻模板至多两条未标记根辐条

设 \(n=24\) 的九度候选有一标记三角形，唯一双邻点为 \(w\)、唯一零点为 \(x\)。三组独有邻点合称 \(Y_1\)，共有十九点。沿用[三角形模板](最大度九的标记三角形模板及五环归约.md)和[删根容量式](二十三点三角形的零点容量与精确重放.md)。令 \(q\) 为未标记根辐条数，\(R=21-q\)，\(r\in\{1,2\}\) 是 \(xw\) 的标记重数，\(b=|N_G(x)\cap Y_1|\)。逐点覆盖给 \(b\ge r+3\)。式 (1) 给 \(2R+r-b\ge31\)，先有 \(1\le q\le4\)。

令 \(A=N_G(w)\cap Y_1\)、\(B=N_G(x)\cap Y_1\)、\(K=A\cup B\)、\(J=Y_1\setminus K\)、\(c=|K|\)。因为 \(xw\) 标记，\(K\) 覆盖 \(Y_1\) 内所有标记。写 \(m_1=e_H(Y_1)\)，则
\[
 |A|\le7-r,\qquad
 m_1\ge95-R-r-(7-r)=67+q,\qquad
 m_1\le7c .
\tag{1}
\]
最后一式来自每个覆盖点在 \(Y_1\) 内的标记度至多七。非零点标记亏损之和为 \(9\cdot23-(196-r)=11+r\)。\(q\) 条未标记根辐条占用 \(2q\) 份，\(x\) 至 \(Y_1\) 的 \(b\) 条未标记边再占 \(b\) 份。因此 \(b\le11+r-2q\)。若 \(q=4\)，则 \(b=r+3\)、\(c\le10\)，与 \(m_1\ge71\) 冲突。

现在设 \(q=3\)。写 \(e\) 为 \(K,J\) 之间的标记数。每个 \(Y_1\) 点有一条根辐条，所以限制宿主到 \(Y_1\) 时 \(K\) 度至多七、\(J\) 度至多八，\(K,J\) 的两侧标记强团 Ore 度至多 15。由[二部标记有理 Ore 界](../多重图两级余量计数.md)有 \(e\le67\)。同时，\(K\) 总标记度等于 \(2m_1-e\)，所以 \(e\ge 2m_1-7c\)。若 \(b=r+3\)，则 \(c\le10\)，结合 \(m_1\ge70\) 得 \(e\ge70\)，矛盾。

余下 \(b=r+4\) 或 \(r+5\)。扣除未标记根辐条及零点的蓝边后，非零点的标记亏损至多一份。因此 \(Y_1\) 全部宿主边均标记，且 \(J\) 也在宿主独立。考虑标记在 \(K,J\) 间但允许 \(K\) 内宿主边。取 \(K\) 一侧的最大标记度点作根；因为跨边全标记，原[逐侧独立 Ore 界](../二部标记独立侧Ore锐界.md)中的未标记邻点修正项为零，得 \(e\le\lfloor15^2/4\rfloor=56\)。因 \(2m_1-e\le7c\)，必 \(c\ge12\)。只有 \(b=r+5\)、\(|A|=7-r\)、\(A\cap B=\varnothing\)、\(c=12\) 能成立，且 \(m_1=70,\ e=56\)。每个 \(K\) 点的 \(Y_1\) 宿主度为七，\(J\) 有七点。

令 \(u\in K\) 实现 \(K\) 侧最高跨标记度。上述逐侧界取等迫使该度为七，故它在 \(Y_1\) 只跨接 \(J\)。若其不同标记邻点数 \(p<7\)，设 \(T\) 为 \(K\setminus\{u\}\) 中有标记连接 \(J\setminus N(u)\) 的点。原逐侧证明中界取等须有 \((7-p)(8-|T|)=0\)，即 \(|T|=8\)。任一 \(u\) 的标记邻点须接到全部 \(T\)，再加其到 \(u\) 的边，宿主度至少九，矛盾。因此 \(p=7\)，即 \(u\) 标记邻接全部 \(J\)。对任何 \(K\) 内标记边 \(vw\)，两端在 \(J\) 的宿主邻域必须覆盖全部七点，才能分别见证七条 \(uJ\) 标记；因为 \(u\) 没有 \(K\) 内边。故 \(H[K]=G[K]\) 的标记 Ore 度至多 \(7+7-7=7\)，但它有 \(70-56=14\) 份标记。以下小引理给矛盾。

## 全标记且 Ore 度至多七的小引理

设一个全标记多重宿主的标记成强团，每点额外平行度至多二，没有重复束属于标记三角形，且每个标记边端点的宿主度数和至多七。则标记数至多 13。

若有三角形 \(C\)，三根度 \(d_1,d_2,d_3\ge2\) 且两两相加至多七。对外点 \(z\) 记 \(t_z=|N(z)\cap C|\)。每条根外标记两端的 \(t_z\) 之和至少二。若 \(z\) 邻接度 \(d_i\) 的根，则 \(d(z)-t_z\le6-d_i\)。根 \(i\) 至多 \(d_i-2\) 条外辐条，故
\[
 m\le\sum_i d_i-3+\tfrac12\sum_i(d_i-2)(6-d_i)\le12.
\]
最后一式只需枚举 \((d_1,d_2,d_3)\) 的降序可能；最大的 \((4,3,3)\) 给 12，若最大值五则另两根均为二。

若无三角形，由独立侧 Ore 界可排除二部图超过 \(\lfloor7^2/4\rfloor=12\) 份。若非二部，最短奇圈是诱导五环，因为全标记的强团无诱导 \(2K_2\)。[五环归约](最大度九的标记三角形模板及五环归约.md)使宿主简单支撑成为完全五环膨胀。五部大小 \(a_i\ge1\)、总数 \(N\)，各部最高度 \(M_i\)。有 \(M_i+M_{i+1}\le7\)、\(\sum_i M_i\le17\)、\(M_i\le a_{i-1}+a_{i+1}+2\)，且 \(N-a_{i+3}\le7\) 对每个 \(i\) 成立，所以 \(N\le8\)。

- 若 \(N=5,6\)，\(\sum_i a_iM_i\le17+4=21\)。其中 \(N=6\) 时唯一增大的部两邻部均单点。
- 若 \(N=7\)，若有三点部则 \(M_i\le4\)；若有两个二点部且相邻，则两个最大度和至多七；若有两个二点部且不相邻，各最高度均至多四。于是 \(\sum_i a_iM_i\le25\)。
- 若 \(N=8\)，若相邻部 \(i,i+1\) 间存在双重束，则该束端点至少额外增加两份 Ore 度，要求 \(a_{i+3}\ge3\)。同时这两端与另一相邻部的标记边各要求 \(a_{i+2},a_{i+4}\ge2\)，得 \(N\ge9\)，矛盾。因此全为单份，令 \(x_i=a_i-1\)，\(\sum_i x_i=3\)。边数为 \(11+\sum_i x_ix_{i+1}\le13\)，因为三个单位可集中在一个部、分到两个部或三个部，三种情形的乘积和分别至多 \(0,2,2\)。

引理得证。故二十四点单双邻三角形只能有一条或两条未标记根辐条。

## 恰两条未标记根辐条时的零点邻点数

现在 \(q=2\)。用上文记号，\(m_1\ge69\)、\(b\ge r+3\)，且 \(b\le11+r-4\)。若 \(b=r+3\)，则 \(c\le10\)，从 \(e\ge2m_1-7c\ge68\) 和 \(e\le67\) 立即冲突。下面排除 \(b=r+4\)。

此时 \(c\le11\) 且 \(e\ge61\)。仍由 \(e\le67\) 知 \(c=11\)，所以 \(|J|=8\)。非零点标记亏损中扣除根蓝辐条和零点的蓝边，剩恰三份，因此整个 \(Y_1\) 至多一条未标记宿主边。若 \(J\) 在宿主独立，则对 \(K\) 最大跨标记度 \(D_K\) 使用[逐侧 Ore 界](../二部标记独立侧Ore锐界.md)，修正至多 \((8-D_K)_+\)，得到
\[
 e\le D_K(15-D_K)+(8-D_K)_+\le57,
\]
因为 \(1\le D_K\le7\)。故唯一未标记边在 \(J\) 内，所有 \(K,J\) 跨边均标记。

取 \(u\in K\) 达到最高跨标记度 \(D\)，其 \(Y_1\) 宿主度为 \(d\le7\)。令 \(A'=N(u)\cap J\)、\(p=|A'|\)。若 \(p=1\)，则 \(D\le2\) 从而 \(e\le2|K|<61\)。故 \(p\ge2\)。若 \(J\) 内唯一未标记边的两端同在或同不在 \(A'\)，独立侧证明在该根所需的局部条件仍成立，给 \(e\le56\)。故记它的两端为 \(y_1\in A'\)、\(y_2\notin A'\)。

令 \(T\) 为那些不等于 \(u\)、不在 \(K\) 内邻接 \(u\)、且标记邻接 \(J\setminus A'\) 的 \(K\) 点。每个 \(t\in T\) 必宿主邻接所有 \(A'\setminus\{y_1\}\)，因为与 \(u\) 的标记需要见证。令 \(T_0\) 为 \(T\) 中不见 \(y_1\) 的点，每个 \(T_0\) 点在 \(J\setminus A'\) 的标记只能到 \(y_2\)。于是 \(|T_0|\le7\)，因为 \(y_2\) 自身宿主度至多八且有一份未标记度。又 \(|T|\le14-d\)，因为任一个 \(A'\setminus\{y_1\}\) 点必须看见 \(T\) 全部和 \(u\)，且它的宿主度至多 \(15-d\)。

依次计与 \(u\) 的 \(K\) 内邻点接触的标记、与 \(T\) 接触的标记，再计 \(A'\) 到 \(K\setminus T\) 的标记。第一项至多 \(D(d-D)\)；第二项至多 \(D|T|\)；第三项至多 \(p(15-d-|T|)+|T_0|-1\)，这里 \(y_1\) 少与 \(|T_0|\) 个点强制相连，但其未标记边本身耗去一份宿主度。合并得
\[
 e\le D(15-D)-(D-p)(15-d-|T|)+|T_0|-1.
\]
若 \(D\le6\)，右边至多 \(54+6=60\)。若 \(D=7\)，必 \(d=7\)、\(|T|\le7\)，而 \(e\ge61\) 强迫 \(p\ge6\)。

若 \(p=6\)，不等式还强迫 \(|T_0|=|T|=7\)。\(A'\setminus\{y_1\}\) 的五点各见 \(u\) 与 \(T\) 全部，故它们全部邻接单份；\(y_2\) 见 \(T_0\) 全部另有一份未标记度，故其跨边也单份。每个 \(T_0\) 点的跨标记度于是仅六，刚才的第二项至少还能减七，矛盾。

若 \(p=7\)，需有 \(|T_0|\ge6\)。任取 \(t\in T_0\)。它见 \(A'\setminus\{y_1\}\) 的六点及 \(y_2\)，用尽七份度，没有 \(K\) 内邻接。任一标记邻接 \(y_1\) 的 \(K\) 点 \(k\)，必须也标记邻接 \(A'\setminus\{y_1\}\) 全部，比较 \(ky_1\) 与 \(t\) 的各相应标记即得。所以这些 \(k\) 也有七个单份跨邻接。由于 \(e\ge61\)，而 \(J\setminus\{y_1\}\) 的六点各至多八份跨标记、\(y_2\) 至多七份，至少有六个这样的 \(k\)。每个 \(A'\setminus\{y_1\}\) 点因此至少见六个 \(T_0\) 点和六个 \(k\)，超过宿主度八，矛盾。

所以 \(q=2\) 时必 \(b\ge r+5\)。若 \(xw\) 是双重束，则 \(r=2\)，由 \(d_G(x)=r+b\le9\) 得 \(b=7\)。这一节尚不排除 \(q=1,2\) 的其它剩余形状。

## 剩余参数的核验

若 \(q=1,r=1\)，则 \(b\ge4\)。假设 \(b=4\)，盖集 \(K\) 至多十点。由 \(m_1\ge68\) 和 \(e\ge2m_1-7|K|\) 得 \(e\ge66\)。然而[整数 Ore 递推](../delta7_parallel_reduction.md)取两侧宿主度上限七和八、Ore 度上限十五、七度侧至多十点、标记边束至多双重，各实际跨标记最大度由一至八的上界是 \(10,20,30,40,50,60,65,62\)。故 \(e\le65\)，矛盾。其余 \(5\le b\le8\)，上限来自 \(x\) 的宿主度。

对 \(q=2,r=1\) 或 \(r=2\)，以及 \(q=1,r=2\)，分别有固定 CNF 的正 RUP 矛盾。对 \(q=1,r=1\) 的 \(b=5,6,7,8\) 四种也分别有正 RUP 矛盾。[生成器](d9_triangle_multigraph_sat.py)中的参数含义见[三角形精确编码](二十三点三角形的零点容量与精确重放.md)。其中参数 --reduced 加入本页 \(q\le2\) 和较弱的 \(q=2\) 时 \(b\ge5\) 约束，以及若 \(xw\) 双重则 \(b\ge6\)（双重根的不同根外邻域并集至少 13 点，迫使两根宿主度至少八）。参数 --cover-cuts 则加本页 \(q=2\) 时 \(b\ge r+5\) 的强化。同一固定 CNF 必用生成时的参数重放。

```powershell
$env:PYTHONPATH = Split-Path -Parent (Get-Location)
$common = @('--select','n24_t1','--strengthened','--reduced','--verify')
python .\d9_triangle_multigraph_sat.py --out d9_triangle_q2_r2 @common --pin-root-blue 2 --pin-zero-marks 2
python .\d9_triangle_multigraph_sat.py --out d9_triangle_q2_r1 @common --cover-cuts --pin-root-blue 2 --pin-zero-marks 1
python .\d9_triangle_multigraph_sat.py --out d9_triangle_q1_r2 @common --cover-cuts --pin-root-blue 1 --pin-zero-marks 2
foreach ($b in 5,6,7,8) {
    python .\d9_triangle_multigraph_sat.py --out "d9_triangle_q1_r1_b$b" @common --cover-cuts --pin-root-blue 1 --pin-zero-marks 1 --pin-zero-blue $b
}
```

由此排除二十四点标记三角形有一个双邻点和一个零邻点的全部情形。没有双邻点的二十四点模板另待处理。
