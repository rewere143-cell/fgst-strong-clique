# 标记支撑无三角形时的统一锐界

设有限无环多重图的最大度为 \(D>0\)，标记强团有 \(m\) 份标记，其不同标记端点对数是 \(s\)。令 \(M=m/D^2\)、\(S=s/D^2\) 和 \(e=(m-s)/m\)。标记支撑是通常的简单图，边是至少有一份标记的端点对。

**定理。** 若标记支撑无三角形，则 \(m\le5D^2/4\)。当 \(D\) 为偶数时，此界可由平衡五环吹胀取到。宿主允许平行边，也允许有未被全标记的三角形。

## 区间覆盖与精确证书

反设 \(M>5/4\)。由[半度余量放电](../多重图五环余量与锚点重数.md)，任一全标记宿主诱导五环均有 \(R/D>1/2\)。因此简单投影在[半度条件证书](conditional_half_certificate.json)中满足 \(L_R\ge q_C/2\)，可用[投影复验器](half_anchor_projection.py)得 \(S\le1.22181\)。于是 \(e>1-1.22181/1.25>.0225\)。[先前大额外份额证书](../多重图五阶旗精确上界.md)给 \(e<.2105\)，而[新五阶证书](red_clique_repeat_refit.json)给 \(M<1.28574\)。这覆盖 [rank6_triangle_density.json](rank6_triangle_density.json) 的固定条件
\[
(M,e)\in[5/4,64287/50000]\times[9/400,421/2000] .
\]

主要六阶矩仍用有限图归一化 \(X(F,T)=Q(F,T)/|\operatorname{Aut}(F,T)|\)，其中 \(Q\) 的归一化分母为 \(2mD^{|V(F)|-2}\)。标签集合 \(T\) 是森林，取值为额外标记实例数的乘积。六位置的新坐标包括无标签坐标及被选用的带标签五环延伸，详见[重建程序](half_anchor_shadow.py)。令 \(Z\) 为 31,073 个保留坐标中图案含有全红三角形的坐标之和。固定证书的目标为 \(-Z\)，其约束保留全部三角形坐标。使用[残差复验器](../multigraph_weighted_maxdeg_exact.py)得
\[
-Z\le-\frac{4225245841430477999084017}{300000000000000000000000000}
<-7/500 .
\]
这与无红三角形时 \(Z=0\) 矛盾。偶数 \(D\) 的平衡构造在五个部各取 \(D/2\) 点，并把相邻部之间的所有边全部标记，即达到上界。

## 一般反例所必需的红三角形

设 \(\tau\) 为标记支撑的红三角形点横截数，取一个大小为 \(\tau\) 的横截集 \(S_\tau\)。任一含红三角形的旗的保色映射至少有一个位置映入 \(S_\tau\)，因为无环宿主上的三角形不能产生重像。对每个位置作并集上界。按全标号旗求和后，由对称性只需固定位置 0 为该位置，并把原来的 \(1/n!\) 系数改成 \(1/(n-1)!\)，其中 \(n\) 是旗的阶数。

对每个全标号图案，选一棵包含标签森林的支撑生成树。固定树和它的标签子集，每个保色映射唯一决定该图案的全部颜色。沿树从已固定到 \(S_\tau\) 的位置 0 求和，未带标签的一步从支撑邻域中选取，带标签的一步按额外实例数加权，二者的和均至多 \(D\)。因此阶 \(n\) 的全标号旗总和可用每棵树的 \(\tau D^{n-1}\) 乘树和标签的选择数来界定。

阶 \(3,4,5\) 的选择数至多 \(n^{n-2}\sum_{k=0}^{\min(3,n-1)}\binom{n-1}{k}\)。阶六的无标签旗可用 \(6^4\) 棵树计数。阶六的带标签旗均保留了一个全红宿主诱导五环，该五环在六个带标号位置中有 72 种选择。一个标签在圈上时，指定标签和圈外连接边最多有 \(5\cdot5\) 种选择；一个标签在圈外时最多 5 种。两个标签只能各有一个圈上和圈外标签，最多 \(5\cdot5\) 种。确定这些选择后，固定地删去一个无标签圈边，再加入已选圈外边，得到所需生成树。故阶六至多需 \(6^4+72(30+25)=5256\) 种选择。

除以 \(2mD^{n-2}\) 并加总各阶，得到 \(Z\le(17911/120)\tau D/(2m)\)。于是
\[
\tau>\frac{7}{500}\frac{2m}{(17911/120)D}>\frac{21D}{89555}>\frac{D}{4300}.
\]
任一极大点不交红三角形组的顶点并必为横截集，所以严格统一界反例有超过 \(D/12900\) 个两两点不交的红三角形。

也可估计不同红三角形数 \(T_3\)。记 \(B\) 为 1 和最大额外标记对重数的较大者。固定旗中的一个红三角形，将它的三个位置收缩；标签森林收缩后环秩至多 2，故可丢去至多两个标签并按 \(B^2\) 上界。剩余标签可包含在收缩支撑的一棵生成树中。给每个像三角形六个定向，沿生成树求和得 \(X(F,T)\le3T_3B^2/(mD)\)。用 \(M>5/4\) 和 \(Z>7/500\) 得
\[
T_3>\frac{7D^3}{37287600B^2}.
\]

## 复验

在本子目录运行

```powershell
python -B half_anchor_shadow.py rank6_triangle_density.json --replay
```

可加 `--vendor <依赖目录>`。独立运行的输出存于 [rank6_triangle_density_replay.log](rank6_triangle_density_replay.log)。证书右值已吸收所有负残差，不依赖双精度优化结果。
