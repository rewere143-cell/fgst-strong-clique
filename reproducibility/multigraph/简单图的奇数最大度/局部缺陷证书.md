# 本阶段共同使用的 \(9/20\) 局部缺陷罚项

对有限简单图中的非空标记强团 \(H\)，设宿主最大度为 \(D\)，标记边数为 \(m\)，各点标记度为 \(h_v\)，全标记三角形数为 \(T(H)\)。[固定有理证书](local_defect_045_certificate.json) 给出
\[
\frac{m}{D^2}+
\frac9{20}\frac{\sum_v h_v(D-h_v)+6T(H)}{2mD}
\le \frac54 .
\]

把宿主扩充为有限 \(D\) 正则简单图，保留原标记边。在每轮取当前两个副本，并在每对尚未满度的对应点之间加一条未标记边。每轮使正的缺度都减一，故有限轮后正则。原分量的标记和见证仍保留。

在三位置模型中，颜色 \(0,1,2\) 分别表示非边、宿主中未标记的边、标记边。每个图案根 \(01\) 标记，另外两列为 \(02,12\) 的颜色。图案 \((2,0,1),(2,1,1),(2,1,2),(2,2,2)\) 对应证书坐标 \(0,2,3,4\)。其有序计数依次为混合诱导楔数、两倍恰有一条标记边的三角形数、两倍恰有两条标记边的三角形数，以及六倍全标记三角形数。这些保色映射必为单射。前三项合起来为 \(\sum_v h_v(D-h_v)\)。每个归一化坐标除以 \(2mD\)。四个坐标的非负余项分别至少为 \(9/20\)，其余余项和 PSD 内积均非负。

在本目录可用 Python 标准库运行：

~~~text
python -B verify_local_defect.py
~~~

脚本重算全部证书余项，再检查四个有理系数。模型系数自身的排序、轨道与生成规则复核沿用 [原附录运行入口](source_snapshot/reproducibility/run_all.py)。[新版论文的模型复跑](新版论文复跑/summary.json) · [罚项证书核验记录](local_defect_045_replay.json) · [四项固定值](local_defect_045_signs.json)
