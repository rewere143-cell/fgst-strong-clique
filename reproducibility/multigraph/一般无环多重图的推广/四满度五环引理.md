# 无三角形多重图的四满度五环引理

设 \(G\) 是有限无环多重图，宿主简单支撑无三角形，最大度为 \(d=2r+1\)。令 \(H\) 为由标记强团边实例组成的子多重图。本笔记讨论满足奇数度初步归约的情形，即每个标记度等于 \(d\) 的顶点都与 \(d\) 个不同端点相连。这样的顶点称为满度顶点。其所有宿主边都标记，且无重边。

**引理。** 若标记图中有一个五环，其中至少四个顶点满度，则 \(e(H)\le d^2+r^2\)。

**证明。** 设五环顶点为 \(c_0,c_1,\dots,c_4\)，其中 \(c_1,c_2,c_3,c_4\) 满度。因无三角形，五环在宿主简单支撑中诱导，且每个顶点在五环上至多有两个邻点。若标记端点 \(x\) 在环上没有邻点，则对任一经过 \(x\) 的标记边 \(xy\)，\(y\) 的环上邻点必须覆盖全环五条标记边，至少要三个，矛盾。若 \(x\) 只有满度点 \(c_i\) 这一个环上邻点，则 \(xc_i\) 是标记边，与 \(c_{i+2}c_{i+3}\) 无跨边，矛盾。

因此可把标记端点分为 \(U_0,\dots,U_4,Z\)。其中 \(U_i\) 由环上邻点恰为 \(\{c_{i-1},c_{i+1}\}\) 的点组成，\(Z\) 由唯一环上邻点是 \(c_0\) 的点组成。下标模 5。各 \(U_i\) 内无宿主边，不连续的两部之间无宿主边，因为相应的两点总有一个共同的环上邻点。\(Z\) 内及从 \(Z\) 到 \(U_1\cup U_4\) 同样无边。\(Z\) 与 \(U_0\) 之间无标记边，因为任何此类边与 \(c_2c_3\) 无跨边。

四个满度环顶点的全部宿主邻点都在标记支撑内，且没有重边。其度数方程给出
\[
|U_0|+|U_2|=|U_1|+|U_3|=|U_2|+|U_4|=|U_3|+|U_0|=d.
\]
故 \(|U_0|=|U_1|=|U_4|=a\)、\(|U_2|=|U_3|=d-a=b\)。因 \(d_G(c_0)\ge 2a\)，有 \(a\le r\)。

五环锚点给出 \(U_0,U_1\) 间全部宿主边。对 \(u\in U_0, v\in U_1\)，比较两条标记边 \(uc_4\) 和 \(vc_2\)，其唯一可能跨边为 \(uv\)。同理 \(U_0,U_4\) 和 \(U_2,U_3\) 间也完全邻接，用到的四个锚点均满度。

若 \(v\in U_1\) 有标记边 \(uv\) 通到 \(U_0\)，对每个 \(w\in U_2\) 比较 \(uv\) 与标记边 \(wc_3\)。唯一可能跨边为 \(vw\)，其他三个端点对属于非连续部。因此 \(v\) 与 \(U_2\) 全部邻接，同时与 \(U_0\) 全部邻接，已有 \(a+b=d\) 个不同宿主邻点，不能有任何平行边。对 \(U_4\) 对称处理。于是连接 \(U_0\) 与 \(U_1\cup U_4\) 的标记份数至多 \(2a^2\)。

其余标记边都有端点在 \(U_2\cup U_3\)。与 \(U_2\cup U_3\) 相接的全部宿主边实例至多 \(2bd-b^2=d^2-a^2\)，因为求和宿主度时至少重复计算了两个部之间的 \(b^2\) 条边。故
\[
e(H)\le 2a^2+d^2-a^2=d^2+a^2\le d^2+r^2.
\]
证毕。

结合[三角形自由情形的奇数度归约](multigraph_bridge.md)，反例的饱和标记顶点必诱导二部链图：若饱和子图有五环，本引理适用；若没有五环，则连通、无三角、无诱导 \(2K_2\) 的饱和子图是二部链图。设其二部为 \(X,Y\)。任何非饱和顶点的满度邻点只可能落在同一侧。若它邻接 \(x'\in X\) 与 \(y'\in Y\)，取链图的通用邻点 \(x\in X\) 与 \(y\in Y\)，则 \(x'y, yx, xy'\) 及这两条邻接给出有四个满度顶点的标记五环。无三角性保证 \(x'\ne x\)、\(y'\ne y\)。
