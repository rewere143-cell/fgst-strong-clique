# 七小时续研中的纯组合余量界

这里的结论针对有限无环多重图。\(D\) 按宿主边实例计度，标记强团的目标为 \(m\le F(D)=D^2+\lfloor D/2\rfloor^2\)。\(R\) 是某个全标记宿主诱导五环的[五部总余量](../多重图五环余量与锚点重数.md)。除另行说明外，只要存在满足表中条件的一个锚圈，就能用所列纯组合证明获得精确界。

| 条件 | 证明 |
| --- | --- |
| 奇数 \(D\)，\(R\le D/2\) | [半度余量的奇数精确界](半度余量的奇数精确界.md) |
| 奇数 \(D\)，\(R\le (D+1)/2\) | [半度再加半格的奇数精确界](半度再加半格的奇数精确界.md) |
| \(D=9,R=5\) | [九度五格锚圈的精确界](九度五格锚圈的精确界.md) |
| \(D=11,R=7\) 或 \(D=15,R=9\) | [十一度七格与十五度九格](十一度七格与十五度九格.md) |
| \(D=13,R=9\) | [十三度九格锚圈的精确界](十三度九格锚圈的精确界.md) |
| \(D=19,R=11\) | [十九度十一格锚圈的精确界](十九度十一格锚圈的精确界.md) |
| 奇数 \(D\)，\(R\le D/2\)，标记图至多 \((5D-1)/2\) 个端点且模板外没有三签名点 | [临界标记阶数与二签名外点的奇数精确界](临界标记阶数与二签名外点的奇数精确界.md) |

[十五度十一格的高签名与相邻零余量](十五度十一格的高签名与相邻零余量.md)另给 \(D=15,R=11\) 的纯组合局部闭合。在至少一个余量位置为零时，它排除至少两个高签名外点，也独立覆盖至少两个相邻零余量位置。单个零余量且至多一个高签名点，以及两个不相邻零余量且至多一个高签名点，并未在该文件中完整处理。

一般的局部工具及早期门槛记录在[额外度单位与半度奇数界](额外度单位与半度奇数界.md)、[五格余量的有限奇数精确界](五格余量的有限奇数精确界.md)、[半度减平方根](半度减平方根的奇数精确界.md)、[三分之一](三分之一余量的奇数精确界.md)、[四分之一](四分之一余量的奇数精确界.md)和[百分之二十三](百分之二十三余量的奇数精确界.md)。前三个包含后续证明反复引用的局部亏损、锚星或矩形计数。

这些条件界与旗代数证书的合并、无合格锚圈的分支和整体结论，由本轮总档案记录。
