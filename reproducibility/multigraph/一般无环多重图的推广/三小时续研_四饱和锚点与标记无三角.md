# 标记支撑无三角形时的四饱和锚点判据

设 (G) 是有限无环多重图，最大度为奇数 (D=2r+1)。设标记强团 (H) 的简单支撑无三角形。选一个全标记的宿主诱导五环 (c_0,c_1,c_2,c_3,c_4)，并假设 (c_1,c_2,c_3,c_4) 的宿主度、标记度和不同宿主邻点数均等于 (D)。令 (a=|N_G(c_1)\cap N_G(c_4)|)。

**定理。** 若 (a\le3) 或 (a=r)，则 (m=|E(H)|\le D^2+r^2)。特别地，(D=9) 时这四个饱和锚点足以推出 (m\le97)。

## 签名与完全邻接

记 (I(v)=N_G(v)\cap\{c_0,\ldots,c_4\})。因为全体接触后四个锚点的宿主边均标记，(I(v)\cap\{c_1,c_2,c_3,c_4\}) 是四点路径中的独立集。若 (v) 邻接其中的 (c_i)，则标记 (vc_i) 与其对侧环边强相邻，(v) 还须见到 (c_{i+2},c_{i+3}) 之一。若 (v) 本身是对侧环边的一个端点，其另一端已在 (I(v)) 中。由此得到下列五部，此外剩余点的签名只可能为零或 \(\{c_0\}\)。

| 部 | 签名 |
| --- | --- |
| (A) | 见 (c_1,c_4)，可能也见 (c_0) |
| (X) | 恰见 (c_0,c_2) |
| (P) | 见 (c_1,c_3)，可能也见 (c_0) |
| (Q) | 见 (c_2,c_4)，可能也见 (c_0) |
| (Y) | 恰见 (c_0,c_3) |

五个锚点分别位于表中顺次各部。后四个锚点的不同度数方程为
\[
 |A|+|P|=|A|+|Q|=|X|+|Q|=|P|+|Y|=D .
\]
所以 \(|A|=|X|=|Y|=a\)，\(|P|=|Q|=b=D-a\)。由于 \(c_0\) 见到 \(X\cup Y\) 的全部 \(2a\) 个不同邻点，\(1\le a\le r\)。

\(A,X\) 间的宿主邻接完整。比较 \(u c_4\) 与 \(v c_2\) 两条标记边，其中 \(u\in A,v\in X\)，唯一可能跨端点见证是 \(uv\)。同理 \(A,Y\) 及 \(P,Q\) 间的宿主邻接完整。接触 \(P\cup Q\) 的标记份数至多 \(2bD-b^2=D^2-a^2\)。因为每部点对共用一个饱和锚点，\(A,X,Y\) 各部内均无标记边。签名为零或仅含 \(c_0\) 的点与 \(A\)、\(X\)、\(Y\) 或同类点之间也无标记边，否则这条标记边无法见证相应的对侧环边。因此余下标记全在 \(A,X\)、\(A,Y\) 或 \(X,Y\) 间。

## 平行份数和遗漏邻接

记 \(s=D-2a\)，它是正奇数。对 \(v\in X\cup Y\)，令 \(\ell_v\) 为它在 \(A\) 中未标记的端点对数。令 \(L=\sum_v\ell_v\)、\(J\) 为 \(A\) 与 \(X\cup Y\) 之间的额外平行标记份数、\(q\) 为 \(X,Y\) 间的标记份数。余下标记共 \(2a^2-L+J+q\) 份。若 \(vw\) 标记且 \(v\in X,w\in Y\)，两端在 \(A\) 中的标记邻域不交，否则有标记三角形。因此 \(\ell_v+\ell_w\ge a\)。这样的边也不能接触 \(c_1\) 或 \(c_4\)，由签名定义可见。

称 \(v\in X\cup Y\) 有正邻接，如果它至少有一个 \(A\) 中的标记邻点。对 \(v\in X\) 有正邻接，固定一条标记 \(uv\)，\(u\in A\)。若 \(w\in P\) 未宿主邻接 \(v\)，则比较 \(uv\) 与 \(wc_3\)，迫使 \(uw\) 是宿主边。这条边必须未标记，因为 \(u,w\) 共享饱和的 \(c_1\)。对 \(Y\) 对称，改用 \(Q\)。因此若 \(v\) 到对应的 \(P\) 或 \(Q\) 遗漏 \(d_v\) 个宿主邻点，每个标记邻点 \(u\in A\) 都有至少 \(d_v\) 个这样的蓝邻点，而 \(d_v\le s\) 由 \(u\) 在 \(X\cup Y\) 中的 \(2a\) 个必备宿主邻点得出。同样，\(v\) 已有 \(a\) 个不同 \(A\) 邻点和 \(b-d_v\) 个不同对应部邻点，故它关联的 \(J\) 和 \(q\) 两类份数之和至多 \(d_v\le s\)。若某 \(u\in A\) 关联一份 \(J\)，则其对应端点 \(v\) 的 \(d_v\ge1\)，从而 \(u\) 至少有一份此类蓝邻接。度数预算给出 \(J\le a(s-1)\)。没有正邻接的 \(v\) 有 \(\ell_v=a\)，且仍有已知的 \(a\) 个不同宿主 \(A\) 邻点，所以它在 \(X,Y\) 间的标记度至多 \(b=a+s\)。

## 奇数度计数

只需证明 \(J+q-L\le r^2-a^2=a(s-1)+(s-1)^2/4\)。将 \(q\) 按正邻接端点数记为 \(q_{00},q_{01},q_{11}\)。令 \(n_0\) 是 \(X\cup Y\) 中没有正邻接的点数。(c_1,c_4) 都有正邻接，且均不参与 \(J\) 或 \(q\)。

- **\(s=1\)。** 此时 \(J=0\)。每个正邻接点在 \(X,Y\) 间标记度至多一。因此 \(q_{01}\le(a-1)n_0\)，同时 \(2q_{00}+q_{01}\le(a+1)n_0\)，相加得到 \(q_{00}+q_{01}\le a n_0\)。对正邻接点之间的标记，\(a q_{11}\le\sum_{v:\ell_v<a}\ell_v\)，因为每边两端遗漏量之和至少 \(a\) 且每个端点至多参与一份。合计 \(q\le L\)。
- **\(a=1\)。** 两个 \(X,Y\) 点仅为对应锚点，故 \(J=q=0\)。
- **\(a=2\)。** 若 \(q=0\)，用 \(J\le2(s-1)\)。否则 \(q\) 的全部标记份数只落在唯一可能的端点对，两端是 \(X,Y\) 各自的非锚点。若两端都有正邻接，\(J+2q\le2s\)、\(L\ge2\)，故 \(J+q-L\le2s-3\)。若仅一端有正邻接，用 \(J+q\le s\) 和 \(L\ge2\)。若两端都没有正邻接，用 \(J=0,q\le s+2,L=4\)。都给 \(J+q-L\le2(s-1)\)。
- **\(a=3\) 且 \(s\ge3\)。** 两部共四个非锚点。若 \(n_0\ge2\)，由正邻接端点总度得 \(J+q\le s(4-n_0)+q_{00}\)，又 \(2q_{00}\le(s+3)n_0\)，所以 \(J+q-L\le4s-(s+3)n_0/2\le3(s-1)\)。若 \(n_0=1\)，则 \(q_{00}=0\)，同一度数计数给 \(J+q-L\le3s-3\)。若 \(n_0=0\) 且 \(q=0\)，直接使用 \(J\le3(s-1)\)。若 \(n_0=0\) 且 \(q>0\)，有 \(L\ge3\)，以及 \(J+2q\le4s,\ J\le3(s-1)\)。所以 \(J+q-L\le(7s-9)/2\le 3(s-1)+(s-1)^2/4\)。

以上覆盖所述的全部情况。将 \(2a^2-L+J+q\le a^2+r^2\) 加到 \(D^2-a^2\)，得所需结论。
