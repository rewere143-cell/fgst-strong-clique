# 九度九格锚圈的精确排除

设最大度为九，反例强团恰含 98 份标记。选取旧核心最大的全标记宿主诱导五环。若总余量为 9，则 \(a_i=s_{i+2}+s_{i+3}\)。将非负整数余量向量在五环旋转及反射下归类，并要求各旧部非空，共有 54 种形状。对边容量计数直接排除 10 种。

其余 44 种各生成两套公式，区分标记支撑是否含三角形。公式与[九度七格的核验](九度七格锚圈的固定核验.md)相同，固定宿主度、总标记 \(98\)、双重标记束数 \(2\) 至 \(17\)，并按标记三角形分别限制支持阶数及干净点结构。外部端点位置数最多 \(9+4\lfloor9/3\rfloor=21\)。全部 88 个固定公式均独立重建、核对哈希及正 RUP 重放通过。含标记三角形的分支重放 3,604,899 条正添加，无标记三角形的分支重放 14,212,325 条。

在一般无环多重图推广目录下，运行以下命令。公式形状由[生成器](d9_pentagon.py)从此前的固定形状检查提取，复验使用原有的正 RUP 检查器。

```powershell
$shapes = & python -B -c "import sys;sys.path.insert(0,'三小时续研_九度矩');import d9_anchor_cases as a;print(*[a.case_name(s) for s in a.patterns(9) if not a.counted_out(s)],sep=chr(10))"
python -B 七小时续研_奇偶变换/d9_pentagon.py --bundles 0 --min-order 24 --select @shapes --out 七小时续研_奇偶变换/d9_r9_triangle_free --strengthen --capacity-cuts --verify
python -B 七小时续研_奇偶变换/d9_pentagon.py --bundles 0 --triangles require --min-order 24 --max-order 25 --select @shapes --out 七小时续研_奇偶变换/d9_r9_triangle --strengthen --capacity-cuts --verify
```
