# 最大度九、23 点支持集的精确界

设简单宿主图 \(G\) 的最大度至多 9。在其标记强团 \(H\) 中固定 98 条标记边。只考虑 \(H\) 的标记支持集恰有 23 个点，删去所有其他宿主点。令 \(A=\{v:d_H(v)=9\}\)、\(U=V(H)\setminus A\)、\(k=|U|\)。由标记度数总和可知
\[
\sum_v(9-d_H(v))=11,\qquad 2\le k\le11.
\tag{1}
\]
所有未标记宿主边位于 \(U\) 内，且至多五条。**结论。** 简单图最大度至多九时，支持集恰为 23 点的标记强团至多有 97 条边。以下先以手工论证归约，再给出其余有限模型的固定证书。

## 1. 标记图中无四团

假设标记四团 \(C\) 存在。对任一 \(C\) 外标记边 \(xy\)，其端点在 \(C\) 中的宿主邻居并集必须覆盖四团的六条边，故总宿主邻居数至少三。令 \(w(x)=d_G(x,C)\)。四团共至多 24 条向外宿主边，且 \(C\) 外的点 \(x\) 至多有 \(9-w(x)\) 条 \(C\) 外标记边。因此三倍 \(C\) 外标记边数至多
\[
\sum_{x\notin C}w(x)(9-w(x))\le8\sum_{x\notin C}w(x)\le192.
\]
总标记边数至多 \(6+24+64=94\)，矛盾。

## 2. 饱和图中有三角形

饱和图 \(J=G[A]=H[A]\) 为诱导 \(2K_2\)-自由图。设其中的三角形是 \(C=(c_1,c_2,c_3)\)。全宿主中所有接触 \(C\) 的边均标记。\(C\) 外顶点依据在 \(C\) 内的邻居数分成 \(Y_0,Y_1,Y_2\)，无点有三个邻居，否则成为标记四团。设 \(t=|Y_2|\)。有 20 个 \(C\) 外顶点及恰 21 条辐条，故
\[
|Y_0|=t-1,\qquad |Y_1|=21-2t,\qquad 1\le t\le10.
\tag{2}
\]
任一 \(Y_0\) 点的标记邻居只能在 \(Y_2\)，因为 \(C\) 外标记边的端点在 \(C\) 内须合起来覆盖三条边。因此若 \(t\le9\)，亏损和至少 \((t-1)(9-t)\)，排除 \(3\le t\le7\)。若 \(t\in\{8,9,10\}\)，除 \(C\) 外有 \(98-3-21=74\) 条标记边，但这些边至多
\[
7t+\binom{21-2t}{2}\le70.
\]
所以只剩 \(t=1,2\)。

### 三个独有邻居组的计数引理

考虑一个诱导 \(2K_2\)-自由简单图，含一个三角形 \(C\)，其余点均有一个或两个 \(C\) 邻居。三个只有 \(c_i\) 邻居的组记为 \(S_i\)。假设每对组的大小和大于最大度 9，且三组之间至少有一条边。则有一对组 \(S_i,S_j\) 存在两个点 \(a_0\in S_i,b_0\in S_j\)，分别邻接对侧的全体。这两点的邻域合起来，在 \(C\) 外覆盖除至多 \(Y_2\) 的点外的所有点。故 \(C\) 外点数至多 \(16+|Y_2|\)。以下给出针对本参数的简证，所用结构也出现在 [Chung、Gyárfás、Tuza、Trotter 的定理 5](https://fanchung.ucsd.edu/mypaps/fanpap/106maxedges.pdf) 的证明中。

同一个 \(S_i\) 内无边，否则与相反的三角形边诱导 \(2K_2\)。对任一双组，组间邻域按包含关系线性排序。否则两个不可比较邻域给出诱导 \(2K_2\)。因而若一对组不存在所述两个点，必有一侧的一个点在另一侧全无邻居。

各对组都必须有一条边。若 \(S_1,S_2\) 无边，不妨取 \(xz\) 在 \(S_1,S_3\) 间。比较 \(xz\) 与每条 \(c_2 y\)（\(y\in S_2\)），得到 \(z\) 邻接所有 \(S_2\)。再比较任一 \(zy\) 与每条 \(c_1 x'\)（\(x'\in S_1\)），得到 \(z\) 邻接所有 \(S_1\)。这超过九度。

若一对组 \(S_1,S_2\) 没有所述两个点，不妨取 \(y_0\in S_2\) 无 \(S_1\) 邻居。取 \(S_1,S_3\) 间一条边 \(x_0z_0\)。比较它与 \(c_2y_0\) 得 \(z_0y_0\)。再比较 \(z_0y_0\) 与每条 \(c_1x\) 得 \(z_0\) 邻接所有 \(S_1\)。由度数和两组大小，\(z_0\) 漏掉某个 \(y_1\in S_2\)。比较每条 \(xz_0\) 与 \(c_2y_1\) 得 \(y_1\) 邻接全部 \(S_1\)。若 \(S_1,S_3\) 也没有所述两个点，则由 \(z_0\) 邻接所有 \(S_1\)，以及前述邻域排序，有一个 \(z_1\in S_3\) 无 \(S_1\) 邻居。比较 \(x_0y_1\) 与 \(c_3z_1\) 得 \(y_1z_1\)。比较 \(y_0z_0\) 与 \(y_1z_1\) 得 \(y_0z_1\)。然而 \(y_0z_1\) 与 \(c_1x_0\) 无见证，矛盾。所以某对组有这两个点。

设所选点是 \(a_0\in S_1,b_0\in S_2\)，两者相邻。其邻域已覆盖 \(S_1\cup S_2\)。将 \(a_0b_0\) 与其余每条 \(c_3\) 的辐条比较，覆盖 \(S_3\) 和所有邻接 \(c_3\) 的 \(Y_2\) 点。每个 \(a_0,b_0\) 已使用一个 \(C\) 内邻居，其邻域在 \(C\) 外的并集至多 16 个点，证毕。

### 用引理排除两种参数

若 \(t=2\)，设 \(Y_0=\{z\}\)，其标记度至多 2。取一条 \(zw\) 的标记边，则 \(w\in Y_2\)。比较它与 \(H[Y_1]\) 的每条边，得到 \((N_G(z)\cup N_G(w))\cap Y_1\) 覆盖 \(H[Y_1]\)。其中任何覆盖顶点的 \(Y_1\) 内标记度至多 7，因为已经有一条到 \(C\) 的辐条和一条到 \(z\) 或 \(w\) 的宿主边。\(w\) 至多有六个 \(Y_1\) 邻居，因为它已有两个 \(C\) 邻居和 \(z\)。另一方面，\(C\) 外 74 条标记边中，最多 14 条接触 \(Y_2\)，其余边都在 \(Y_1\)。因此
\[
60\le e(H[Y_1])\le7(6+|N_G(z)\cap Y_1|).
\]
故 \(z\) 至少有三个 \(Y_1\) 宿主邻居，边均未标记。因 \(z\) 的标记亏损至少七，其他所有点的标记亏损和至多四。三条从 \(z\) 出发的未标记边已耗掉其他点的三个亏损单位。没有另一条两端都不是 \(z\) 的未标记边。因此删去 \(z\) 后宿主全部边标记，诱导图是 \(2K_2\)-自由。每个独有组 \(S_i\) 至少五点，因为 \(c_i\) 有七条外部辐条，至多两条到 \(Y_2\)。现在三组之间有边，且每对组大小之和至少十。计数引理将剩余 \(C\) 外点数界为 \(16+2=18\)，实际有 19 点，矛盾。这段不限制 \(k\)。

若 \(t=1\)，各独有组大小为 \(6,6,7\)。假若全部未标记宿主边有至多两点的点覆盖，删去这两点。可以选择覆盖只包含未标记边的端点，故不碰及 \(C\)。余下宿主全部边标记，因此诱导 \(2K_2\)-自由。各对独有组大小之和仍至少十。原来 \(H[Y_1]\) 至少 \(74-7=67\) 条边，删至多两点后仍有边。计数引理给出 \(C\) 外点数至多 \(16+1=17\)，实际至少 18 点，矛盾。若 \(k\le4\)，未标记图只在至多四点上且至多五边，总有一个至多两点覆盖，所以该参数也已排除。

## 3. 饱和图无三角形，至多四个未饱和点

若 \(k\le4\)，则 \(J\) 有至少 19 点，没有孤立点，一个孤立的饱和点否则需要九个 \(U\) 邻居。在无三角形、诱导 \(2K_2\)-自由图中，若二分则是链图，两侧各有一个通用邻点，故每侧至多九点。否则是五环完全吹胀。后一性质可由最短奇环得到。它是诱导五环，每个非孤立点的五环邻域恰有两个彼此不相邻的点。一个邻点会留下诱导 \(2K_2\)，零邻点则迫使其某个邻点的五环邻域覆盖整环。按五环邻域分部，连续两部完全邻接，是由比较各自朝远侧的五环边强制的。其他两部间以及部内无边，因为它们的点共享五环邻居。也可参看[同一论文的定理 2](https://fanchung.ucsd.edu/mypaps/fanpap/106maxedges.pdf)。

因链图至多 18 点，只需 \(J\) 是五环吹胀。记五部大小为 \(a_i\)，各部的 \(U\) 剩余度数为 \(r_i=9-a_{i-1}-a_{i+1}\in[0,k]\)。以下下标模五。若外点 \(x\) 与 \(a\in A_i\) 有标记边，则比较 \(xa\) 与每个对侧 \(A_{i+2},A_{i+3}\) 间标记边，得到 \(x\) 必须与其中一部完全邻接。因此
\[
r_i\le r_{i+2}+r_{i+3}.
\tag{3}
\]
因为每点 \(a\in A_i\) 有 \(r_i\) 个 \(U\) 邻居，能完全邻接某部 \(A_j\) 的外点至多 \(r_j\) 个。

写 \(R=\sum_i r_i=2k-1\)。解五个线性方程，有 \(a_i=5-k+r_{i+2}+r_{i+3}\)。令 \(E_r\) 为下标的补五环上 \(r_i r_j\) 的边和。计 \(A,U\) 间标记边得
\[
M=(5-k)R+2E_r\le9k-11,\qquad
\sum_i r_i^2\le2E_r,
\tag{4}
\]
后者来自 (3)。

若 \(k=2\)，(4) 给 \(M\ge9>7\)。若 \(k=3\)，则 \(R=5\)、\(E_r\le3\)。由 \(\sum_i r_i^2\le6\) 得五个 \(r_i\) 都为 1，但这给 \(E_r=5\)。若 \(k=4\)，则 \(R=7\)、\(E_r\le9\)、\(\sum_i r_i^2\le18\)。按从大到小排序，可能的互异数组为
\[
(2,2,1,1,1),\quad(2,2,2,1,0),\quad(3,1,1,1,1),\quad(3,2,1,1,0),\quad(3,2,2,0,0).
\]
第三组的 3 没有足够大的相邻值，违反 (3)。第二组在补五环的四点正支撑路径上，1 只能在端点，给 \(E_r=10\)。第四组的 3 必与 2、1 相邻，路径上 \(E_r\ge10\)。第五组的 3 必与两个 2 相邻，给 \(E_r\ge12\)。第一组要求两个 2 在补五环上不邻接，否则 \(E_r=10\)。于是从原五环中相邻的两个 2 起重标，有
\[
(r_i)=(2,2,1,1,1),\qquad (a_i)=(3,3,4,5,4).
\]
第 0 部每点的两个外部邻居，必须分别完全邻接第 2 部和第 3 部。这两部的余量均为 1，故该邻接第 3 部的外点也完全邻接第 0 部。对第 1 部同理，该外点也完全邻接第 1 部。其宿主度至少 \(3+3+5=11\)，矛盾。

结合三角形分支，\(2\le k\le4\) 全部排除。将 11 分成 \(k\) 个正亏损且每份至多八，\(k=2,3,4\) 分别有 3、9、11 种无序分布。



## 4. 饱和链图的一侧有九点，另一侧至少七点

设 \(J\) 是饱和图，且为双侧大小 \(9,9-\ell\) 的二分链图，\(0\le\ell\le2\)。以 \(X\) 为九点侧，\(Y\) 为另一侧，\(k=5+\ell\)。考虑二分补图 \(B=K_{X,Y}-J\)，它仍是二分链图，因为补集反转同侧邻域的包含关系。由每点饱和，
\[
98=9(|X|+|Y|)-e(J)+e(H[U])=81+e(B)+e(H[U]).
\tag{5}
\]
写 \(F=e(H[U])\)。

链图的 \(Y\) 侧有一个与所有 \(X\) 点相邻的点 \(b_0\)，故它没有任何 \(U\) 邻居。对任一 \(U\) 内标记边 \(xy\)，与全部 \(b_0a\)（\(a\in X\)）比较，迫使 \(x,y\) 的 \(X\) 邻域并集为整个 \(X\)。因此
\[
d_{H[U]}(x)+d_{H[U]}(y)\le 16-9=7.
\tag{6}
\]
对标记边求和得 \(\sum_v d_{H[U]}(v)^2\le7F\)，柯西不等式给 \(4F\le7k\)（\(F>0\)）。若 \(B\) 为空，(5) 给 \(F=17\)，与 \(k\le7\) 矛盾。

所以 \(B\) 非空。由于 \(B\) 是链图，所有非孤立点在同一个连通分量。记其两侧为 \(X_B,Y_B\)。\(X\setminus X_B\) 是 \(J\) 的通用 \(X\) 点，各有恰 \(\ell\) 个 \(U\) 邻居。设 \(Z\subseteq U\) 是这些外部邻域的交。故 \(|Z|\le\ell\)，且每个 \(z\in Z\) 邻接 \(X\setminus X_B\) 的全部点。

若 \(x\in U\) 邻接 \(b\in Y_B\)，则它必须邻接 \(b\) 在 \(B\) 中的所有邻点。这是比较 \(xb\) 与 \(b_0a\)（\(ba\in E(B)\)）的结果，因为 \(b_0\) 与 \(x\) 不邻接且 \(Y\) 内无边。反过来，若 \(x\notin Z\) 邻接 \(a\in X_B\)，选一个不邻接 \(x\) 的通用 \(X\) 点 \(a_0\)。比较 \(xa\) 与 \(a_0b\)（\(ab\in E(B)\)），可见 \(x\) 邻接 \(a\) 的全部 \(B\) 邻点。于是每个 \(x\in U\setminus Z\) 要么不接 \(B\) 的非孤立点，要么接全部的这些点。后一种点组成 \(T\)，记 \(t=|T|\)。

\(B\) 的 \(Y_B\) 侧有一个邻接全部 \(X_B\) 的点 \(b^\star\)。若 \(z\in Z\) 邻接 \(b^\star\)，则它还邻接全部 \(X_B\) 和全部 \(X\setminus X_B\)，有九个饱和标记邻居，与 \(z\in U\) 矛盾。故 \(b^\star\) 的全部 \(U\) 邻居来自 \(T\)。\(Y\) 侧每个点的 \(U\) 度等于其 \(B\) 度，所以 \(|X_B|=t\)。每个 \(Y_B\) 点又都邻接 \(T\) 全体，其 \(B\) 度至少 \(t\)，故 \(B[X_B,Y_B]\) 为完全二部图，且 \(Z\) 中的点都不接 \(Y_B\)。写 \(q=|Y_B|\)。由 \(T\) 中点的标记度，有 \(t+q\le8\)。

\(X_B\) 的每个点有 \(U\) 度 \(\ell+q\)，其中 \(t\) 个来自 \(T\)，其余 \(s=\ell+q-t\) 个来自 \(Z\)。各 \(z\in Z\) 在 \(X_B\) 中至多有 \(t-1\) 个邻居，因为它同时邻接 \(X\setminus X_B\) 的所有点。由此
\[
t-\ell\le q\le t-1\quad(\ell>0),\qquad
ts\le |Z|(t-1).
\tag{7}
\]
当 \(\ell=0\) 时 \(q=t\)，且 \(X\setminus X_B\) 不接 \(U\)。由其非空性和 \(U\) 内标记边覆盖 \(X\) 的性质知 \(F=0\)，而 (5) 要求 \(t^2=17\)。

当 \(\ell=1\) 时，(7) 给 \(q=t-1\) 且 \(t\le4\)。若通用 \(X\) 点的唯一 \(U\) 邻居并非同一个点，则每条 \(U\) 内标记边都必须经过其中两个固定的不同邻居，所以 \(F\le1\)。若这个邻居恰是同一点 \(z\)，则所有 \(U\) 内标记边都须经过它。由于 \(z\) 已邻接 \(9-t\) 个通用点，其外部标记度至多 \(t-1\)。两种情况均使 \(t(t-1)+F\le15<17\)。

当 \(\ell=2\) 时，\(q=t-2\) 或 \(q=t-1\)。若 \(q=t-2\)，则 \(3\le t\le5\)，且 \(s=0\)。所以任何 \(U\) 内标记边要覆盖 \(X_B\)，必须经过 \(T\)。\(T\) 内每点已用掉 \(t+q\) 度数，故
\[
F\le t(8-t-q).
\]
对 \(t=3,4,5\)，右侧依次为 \(12,8,0\)，均低于 \(17-t(t-2)=14,9,2\)。

若 \(q=t-1\)，则 \(s=1\)，(7) 强制 \(Z\) 恰两点，且 \(2\le t\le4\)。两点之间以外的所有 \(U\) 内标记边仍须经过 \(T\)，因此 \(F\le t(8-t-q)+1\)。对 \(t=2,3\)，右侧分别为 \(11,10\)，都低于 \(17-tq=15,11\)。对 \(t=4\)，存在第七个 \(U\) 点不在四点的 \(T\) 或两点的 \(Z\) 中。它不能接任何 \(X_B,Y_B\) 点，且通用 \(X\) 点的两个邻居已被 \(Z\) 用尽。通用 \(Y\) 点没有 \(U\) 邻居。因此它没有 \(A\) 内邻居。任何涉及它的 \(U\) 内标记边都需要另一端独自覆盖 \(X\) 全体，超过另一端至多八的标记度。于是该点没有标记边，违反支持集条件。



## 5. 饱和链图的两侧各八点

此时 \(k=7\)。保留上一节的二分补图 \(B\)，令 \(F=e(H[U])\)。这里
\[
e(B)+F=18.
\tag{8}
\]
若 \(B\) 为空，任何 \(U\) 内标记边的两端在 \(A\) 中必须合起来覆盖完全二部图的一整个侧，至少用去八条接入 \(A\) 的标记边。其 \(U\) 内标记端点度数和至多八。再次用柯西不等式得 \(4F\le8k=56\)，与 \(F=18\) 矛盾。

因此 \(B\) 有一个由所有非孤立点组成的分量，记其两侧为 \(X_B,Y_B\)。令 \(X_\ast,Y_\ast\) 为 \(J\) 两侧的通用点集合。它们均非空，每点恰有一个 \(U\) 邻居。记这两侧的所有单邻居汇集成集合 \(D_X,D_Y\subseteq U\)。任何 \(U\) 内标记边 \(uv\) 的端点集合必须包含整个 \(D_X\) 或整个 \(D_Y\)。否则能选出各侧一个通用点，其唯一的外部邻点均不在 \(\{u,v\}\)，而连接该通用点对的标记边与 \(uv\) 无见证。

当 \(D_X=\{z_X\}\) 时称 \(z_X\) 为 \(X\) 的特殊点，同样定义 \(Y\) 的特殊点。除去零到两个特殊点，任何外点在 \(B\) 非孤立分量中要么没有邻点，要么邻接所有点。这仍是上一节的比较。对某个外点 \(x\)，如果它不特殊于 \(X\)，可选一个不邻接 \(x\) 的 \(X\) 通用点做见证，强制 \(x\) 从它标记的 \(X_B\) 点沿每条 \(B\) 边邻接 \(Y_B\)。反方向在 \(x\) 不特殊于 \(Y\) 时相同。令 \(T\) 为邻接整个 \(B\) 分量的非特殊点集合，\(t=|T|\)。由于 \(B\) 非空且每个非孤立饱和点至少需要两个外部邻居，下列各情形都有 \(t>0\)，仅有两个不同特殊点时也可由下面的 \(p,q\le t\) 推出。写 \(p=|X_B|,q=|Y_B|\)。每个 \(B\) 点的 \(B\) 度为 \(t-1\) 加上它的特殊邻居数，因为在 \(J\) 中每侧比九少一。还有 \(p+q\le8\)，由 \(T\) 中点的标记度。

若没有特殊点，\(B\) 的非孤立分量是正则链图，故为 \(K_{t-1,t-1}\)。两集合 \(D_X,D_Y\) 均至少两点，因此最多产生两条 \(U\) 内标记边。只有 \(t-1=4\) 可能达到 (8)。但此时五个 \(T\) 点的标记度八全部给 \(B\) 分量，\(X_\ast,Y_\ast\) 只能邻接剩下两个 \(U\) 点。这样 \(D_X=D_Y\)，故 \(F\le1\)，仍不够。

若两侧的特殊点是同一个 \(z\)，则所有 \(U\) 内标记边必须经过 \(z\)。\(z\) 邻接全部 \(X_\ast\cup Y_\ast\)，其大小为 \(16-p-q\)。由 \(p+q\le8\) 和 \(d_H(z)\le8\)，只能有 \(p+q=8\) 且 \(d_H(z)=8\)。它于是既不再邻接 \(B\) 分量，也不能提供 \(U\) 内标记边。\(B\) 仍为正则链图，相应 \(e(B)=16\)，与 (8) 矛盾。

若只有 \(X\) 侧有特殊点 \(z\)，考虑 \(B\) 中邻接全部 \(X_B\) 的一个 \(Y_B\) 顶点 \(b^\star\)。由于 \(z\) 并非 \(Y\) 侧的特殊点，若它邻接 \(b^\star\)，它也必须邻接所有 \(X_B\)。又 \(z\) 邻接所有 \(X_\ast\)，总共已有九个标记邻居（含 \(b^\star\)），矛盾。故 \(b^\star\) 的 \(B\) 度恰为 \(t-1\)，而所有 \(Y_B\) 点的 \(B\) 度至少 \(t-1\)。所以 \(p=t-1\)，\(B\) 分量完全二部，且 \(z\) 不接 \(Y_B\)。对 \(X_B\) 的点数度数，得 \(q=t\) 或 \(q=t-1\)。在 \(q=t\) 时 \(z\) 邻接整个 \(X\)，没有 \(U\) 内标记度。由于 \(D_Y\) 至少两点，\(F\le1\)，而 \(e(B)=t(t-1)\le12\)。在 \(q=t-1\) 时 \(z\) 只邻接 \(p\) 点以外的通用 \(X\) 点，剩余标记度至多 \(p\)。加上不经过 \(z\) 的至多一条标记边，得 \(F\le p+1\)。若 \(p\le3\)，它与 \(e(B)=p^2\) 之和至多 13。若 \(p=4\)，五个 \(T\) 点已经用完标记度，只余两个 \(U\) 点可以提供至多一条内部标记边，和至多 17。

最后两侧有不同的特殊点 \(z_X,z_Y\)。同理，\(B\) 中与 \(X_B\) 完全邻接的 \(Y_B\) 点不能邻接 \(z_X\)，相反侧对称。因此 \(p,q\in\{t-1,t\}\)。所有 \(U\) 内标记边必须经过 \(z_X\) 或 \(z_Y\)。

- 若 \(p=q=t-1\)，则 \(B\) 完全，两个特殊点都没有 \(B\) 邻居，各最多提供 \(p\) 条 \(U\) 内标记边。\(p\le3\) 时 \(e(B)+F\le p^2+2p\le15\)。\(p=4\) 时五个 \(T\) 点已用满标记度，内部标记只能在两个特殊点之间，给 \(e(B)+F\le17\)。
- 若 \(p=t,q=t-1\)，则 \(X_B\) 点的 \(B\) 度至少 \(t-1=q\)，故所有 \(B\) 边齐全。每个 \(Y_B\) 点有 \(B\) 度 \(t\)，因而恰有一个特殊邻居，并且由于其在 \(B\) 中邻接全部 \(X_B\)，这个特殊邻居只能是 \(z_Y\)。\(z_Y\) 遂邻接整侧 \(Y\) 且无 \(U\) 内标记边。\(z_X\) 还可提供至多 \(t\) 条，得 \(e(B)+F\le t^2\le16\)。另一不对称情形相同。
- 若 \(p=q=t\)，则 \(B\) 在两个非孤立侧之间的非边构成匹配，因为两侧最小 \(B\) 度至少 \(t-1\)。而 \(B\) 是链图，该匹配至多一条，否则两个行邻域不可比较。若 \(B\) 完全，两个特殊点均邻接各自整个八点侧，不提供 \(U\) 内标记边，故和至多 16。若恰缺一边，则每个特殊点邻接各自侧除该缺边端点外的七个点。故两者总剩余标记度至多二，\(e(B)+F\le t^2-1+2\le17\)。

这些都与 (8) 矛盾。至此排除所有 \(k\le7\) 的饱和链图。若 \(k\le7\)，饱和图中的孤立点无法用 \(U\) 补足九度，因而三角形自由的饱和图只有链图和五环吹胀两个分支。

## 6. 五环吹胀的有限补充核验

对 \(5\le k\le7\) 的五环吹胀分支，[独立枚举程序](d9_n23_c5_saturated.py) 进一步排除全部完成图。程序先用 (3) 和 (4) 列出五部大小。对于每个外点，列出它所完整邻接的核心部集合，按外点重标号排序。对每个核心部，枚举各点的外部邻域。每个邻域必须包含该部全部的完整外邻点。由 (3) 的见证要求，邻域中的每个外点都要完整邻接两对侧部之一。同一部内按邻域排序，并检查这些邻域的交恰为所指定的完整邻点。以上两种排序都只除去同构标号。

核心和跨部边全部标记。对外部标记数，使用 \((9k-11-M)/2\)。外部标记边须由其两端在核心中的邻域覆盖所有核心边。对两个跨部标记边唯一可能取作额外见证的外部宿主边，直接强制存在。最后检查外部标记度、宿主度、所有其余见证子句。若见证子句尚未满足，则穷举从其候选边中选一条、扣去相应端点容量，直到所有子句满足或度数耗尽。每一步都是必要且穷尽的。

运行结果中，\(k=5,6,7\) 的五部分型数分别为 \(8,18,30\)，通过核心与外点邻接初筛的分型分别为 \(1,50,459\)，均无法完成。复现命令为
```sh
python -B d9_n23_c5_saturated.py --maximum 7
```
因此 \(k\le7\) 时，如果饱和图无三角形就不能有反例。若饱和图有三角形，仅剩第 2 节的 \(t=1\) 且未标记图最小点覆盖至少三的情形。\(k\ge8\) 也仍有未覆盖情形。



## 7. 再排除四种五点亏损分布

若 \(k=5\)，上一节和第 4 节已排除无三角形饱和图。所以任何可能反例须有第 2 节的 \(t=1\)，且五点上的未标记图的点覆盖数至少三。后者等价于其独立数至多二，并且迫使至少三个点的未标记度至少二。否则取三个未标记度至多一的点。若它们独立即矛盾。若其中 \(x,y\) 相邻，则 \(x,y\) 都不邻接其他三个点。剩下三点中至少有一个未标记度至多一，故三点之间有非邻接对。这一对与 \(x\) 构成独立三点，仍矛盾。

未标记度不超过标记亏损。因此 \(k=5\) 时，下列四个亏损数组同样排除：
\[
(1,1,1,1,7),\quad (1,1,1,2,6),\quad (1,1,1,3,5),\quad(1,1,1,4,4).
\]
加上第 3 节结果，全部 52 种 23 点标记度分布中已排除 27 种。其余分布还受到饱和图结构与未标记边点覆盖的约束。

\(k=5\) 时五环吹胀枚举唯一通过核心与外点邻接初筛的分型为 \(a=(3,3,4,4,4)\)、\(r=(2,2,2,1,2)\)，五个外点的跨边标记度为 \(0,8,8,8,8\)，总跨边数 32。外部尚需一条标记边而只有一个点可以再增加标记度，故不可能完成。




## 8. 排除饱和三角形的最后分支

在第 2 节的计数引理中，各独有组两两大小之和只需至少九。证明中的第三组顶点已有一条到 \(C\) 的辐条，最多有八个 \(C\) 外邻居。所以它不能同时邻接两个组的至少九个点，选择 \(y_1\) 的论证也相同。

假设还有一个 \(t=1\) 的反例。把唯一有两个 \(C\) 邻居的点记成 \(w\)，不妨令其邻接 \(c_1,c_2\)。三个独有组依次为 \(X,Y,Z\)，大小分别为 \(6,6,7\)。下面排除该反例。

### 第三个独有组的重标记

\(H[X,Y]\) 在 \(G[X\cup Y]\) 中是二分标记强团。每条标记边 \(xy\) 必与所有 \(zc_3\)（\(z\in Z\)）强相邻，故 \(x,y\) 的 \(Z\) 邻域并集为 \(Z\)。两个端点各已经有一条原 \(C\) 辐条。因此
\[
d_{G[X\cup Y]}(x)+d_{G[X\cup Y]}(y)\le16-7=9.
\tag{9}
\]
使用 [整数 Ore 递推](d7_bipartite_ore_coupled.py) 的参数 \((\ell,r,\sigma,q)=(8,8,9,6)\)，且一对标记端点至多一份，由实际标记最大度 \(D=1,\ldots,6\) 得上界 \(6,12,18,22,22,19\)。特别地，\(e_H(X,Y)\le22\)。该递推及固定根版本在 [最大度七证明第 3 节](../一般无环多重图的推广/delta7_parallel_reduction.md) 中详证，参数与证明均允许这里的二分标记图和非二分宿主。

考虑另一个标记三角形 \(C'=(c_1,c_2,w)\)。写 \(a=d_G(w,X\cup Y)\)、\(b=d_G(w,Z)\)，于是 \(a+b\le7\)。相对于 \(C'\)，在 \(C'\) 外没有三个邻居的点。两个邻居的点恰为 \(c_3\) 和 \(w\) 在 \(X\cup Y\) 的 \(a\) 个邻居。没有 \(C'\) 邻居的恰为 \(Z\) 中 \(7-b\) 个不邻接 \(w\) 的点。它们的标记邻居只能是上述 \(a+1\) 点，否则同 \(C'\) 中一条标记边没有见证。因而
\[
(7-b)(8-a)\le11,\qquad a+b\le7.
\tag{10}
\]
从 (10) 得 \(a\in\{0,1,7\}\)。

若 \(a=7\)，则 \(b=0\)，七个 \(Z\) 点的亏损至少七。\(X\cup Y\) 中五个不邻接 \(w\) 的点也没有任何 \(Z\) 标记邻居，所以其标记边除了那条 \(C\) 辐条，都在 \(X,Y\) 之间。这五点的亏损和至多四。它们在 \(H[X,Y]\) 中的度数和至少 \(5\cdot8-4=36\)，二分图五点内至多六条边，故 \(e_H(X,Y)\ge30\)，违反 (9) 的 22 条上界。

若 \(a=1\)，则 \(b=6\)，相对于 \(C'\) 恰有一个零邻居点 \(z\) 和两个双邻居点。记新的三个独有组的并为 \(Y'_1\)。\(C'\) 内的三条边标记，其向外标记辐条至多 21 条，所以 \(C'\) 外至少 74 条标记边。接触两个双邻居点的至多 14 条，零邻居点只能和双邻居点有标记边。因此 \(e(H[Y'_1])\ge60\)。取一条从 \(z\) 到双邻居点 \(u\) 的标记边，它迫使 \((N_G(z)\cup N_G(u))\cap Y'_1\) 覆盖全部这些边。每个覆盖点在 \(Y'_1\) 中的标记度至多七，因为它已有一条宿主辐条和一条通往 \(z\) 或 \(u\) 的宿主边。\(u\) 至多提供六个覆盖点，所以 \(z\) 至少有三个这样的未标记邻居。又 \(z\) 的亏损至少七，其他点的亏损和至多四。如第 2 节，所有未标记边都须经过 \(z\)，与原 \(t=1\) 必须有至少三点未标记边覆盖矛盾。这里不需要 \(C'\) 的所有辐条标记。

若 \(a=0\)，则 \(b\in\{6,7\}\)。\(b=6\) 时唯一的零邻居点只可能与 \(c_3\) 有标记边，亏损八。其他点共三个亏损单位，未标记边中至多一条不经过该点，给至多两点覆盖，仍矛盾。

于是 \(a=0,b=7\)。\(w,c_3\) 在宿主图中不相邻，却有完全相同的邻域 \(\{c_1,c_2\}\cup Z\)。任一现有标记边若既不经过 \(w,z\) 也不经过 \(c_3\)，它与 \(wz\) 是否强相邻等同于它与 \(c_3z\) 是否强相邻。若它经过 \(c_3\) 而不经过 \(w,z\)，则 \(zc_3\) 提供见证。故可将全部 \(wZ\) 边标记。若因此增加了 \(r\) 条标记边，再取消恰 \(r\) 条 \(XY\) 标记，恢复标记总数 98。这样做总有足够 \(XY\) 标记边：原来的 \(e_H(X,Y)=18+\sum_{z\in Z}(9-d_H(z))\ge18\)，是把 \(c_1,c_2,c_3,w\) 的 31 个宿主边位和 \(Z\) 的跨组标记边计数相加得到的，去掉的 \(wZ\) 标记数在这两项中相抵。且 \(r\le5\)。四个根顶点的标记度在新标记图中均是九，23 个顶点仍有正标记度。原来的 \(t=1\) 分组未改变。以下使用这个新的标记强团。

令 \(D_Z=\sum_{z\in Z}(9-d_H(z))\)。四个根顶点关联恰 31 条标记边，\(Z\) 到 \(X\cup Y\) 恰 \(49-D_Z\) 条。因此
\[
e_H(X,Y)=18+D_Z,\qquad D_Z\le4.
\tag{11}
\]
特别是至少三个 \(Z\) 点饱和。任取一个饱和 \(Z\) 点，把其 \(X,Y\) 标记邻域大小记为 \(p,7-p\)。比较它的标记边与异侧已有的根辐条，得到 \(XY\) 中的宿主边，必须包含其 \(Z\) 点邻域与非邻域之间的两类跨组点对。这些边数为
\[
p(p-1)+(6-p)(7-p).
\tag{12}
\]
若 \(p=1\) 或 6，则 (12) 等于 30，超过 \(e_H(X,Y)+5\le27\)。交换 \(X,Y\) 后可取 \(p\in\{2,3\}\)。这七个邻居可约定各自在其组内占据最前面的位置。

### 排除 \(D_Z=0\)

此时 \(e_H(X,Y)=18\)，故 \(XY\) 宿主边至多 23。若首个 \(Z\) 点邻域的两部分别为 \(X_0,Y_0\)，则它已经强制 (12) 的 \(XY\) 宿主边。另一个 \(Z\) 点也是饱和，它改变的邻接点由两块组成，即从 \(X_0\cup Y_0\) 去掉 \(j\) 个，向其补集加入 \(j\) 个。新强制的宿主边是在两个矩形 \(X_0\times Y_0\) 和 \((X\setminus X_0)\times(Y\setminus Y_0)\) 各自由这一点集切开的边。两块切边数相加。

若 \(p=2\)，第一行强制 22 条边，故另一行至多新加一条边。\(K_{2,5}\) 的非平凡割至少两条边，所以对第一块要么不改变，要么改变七点。第二块只有五点，不能同时改变七点。因此七个 \(Z\) 点的邻域都相同。但每个 \(Y_0\) 点于是除了七个 \(Z\) 邻点，还有四个强制 \(X\) 邻点，超过九度。

若 \(p=3\)，两块矩形为 \(K_{3,4}\)、\(K_{3,2}\)，至多新加五条边。按 \(j=0,1,\ldots,5\)，两个矩形割边数的总下界分别为 \(0,5,8,9,8,5\)。这些数可将 \(j\) 点分到每个矩形两侧，计算 \(x(q-y)+y(p-x)\)，其中 \(p,q\) 是该矩形两侧大小，\(x,y\) 是选中的点数。\(j=1\) 取等时，第一块只删除一个 \(Y_0\) 点，第二块只加入一个 \(X\setminus X_0\) 点。\(j=5\) 取等时，第一块只保留一个 \(X_0\) 与一个 \(Y_0\) 点，第二块五点全部加入。两种非原行必须各新加强制边五条。所有非原行的新增边集合必须相同，否则其并连同原来的 18 条边超过 23。新增边集合唯一确定是哪一种取等及选了哪些点。因此七行只有两种不同的行。两种行至少共用一个 \(X_0\) 里的邻居，在 \(j=1\) 时共用全部 \(X_0\)，在 \(j=5\) 时共用保留的那个 \(X_0\) 点。这个公用点看见全部七个 \(Z\) 点，还必须邻接 \(Y\setminus Y_0\) 的两点，再加自己的原 \(C\) 辐条，超过九度。[独立小整数枚举](d9_n23_twin_triangle.py) 验证同一结论。

### \(D_Z\in\{1,2,3,4\}\) 的固定证书

以下附加条件在该分支是必要的。未标记图没有包含 \(Z\) 中点的三点覆盖。否则删去这三点，所得图全部宿主边标记。剩余各独有组两两大小和至少九，且剩余的 \(H[Y_1]\) 有边。计数引理对 \(C\) 的 17 个外点应用。若其给出的是组 \(X,Z\) 或 \(Y,Z\) 的通用点对，未被覆盖的一点 \(w\) 也会通过剩余第三组的根辐条覆盖，至多只能有 16 点。因此通用相邻点对为 \(a_0\in X,b_0\in Y\)。其 \(C\) 外邻域须共覆盖 16 点，而每个点还有一条 \(C\) 辐条，于是两点在删点后都达到九度。原宿主中它们也不能接入任何已删点。取一个已删的 \(z\in Z\)，则原来的标记边 \(zc_3\) 与标记边 \(a_0b_0\) 无见证，矛盾。

由 \(p=2,3\) 和 \(D_Z=1,2,3,4\) 得八个固定布尔公式。[生成器](d9_n23_twin_sat.py) 对 19 个外点编码宿主与标记位，四个根点的邻接与标记已固定。每个 \(X,Y\) 外点的自由宿主度至多八，每个 \(Z\) 点至多七。组内仅允许未标记宿主边。组间要求强团条件，并比较标记边与第三组的全部根辐条。还编码至多五条未标记边、(9) 的 Ore 度约束、(11) 的两个边数、所选饱和 \(Z\) 点的邻域、上述三点覆盖禁止、以及 [整数 Ore 递推](d7_bipartite_ore_coupled.py) 的实际标记最大度与固定最大度根约束。后者只在所属参数满足时使用。未固定的同类外点取全图按上三角读取的字典序最大标签，故相邻交换约束不丢失解。八份 CNF 全部有通过精确 RUP 重放的不可满足证书。于是饱和图含三角形的所有情形均已排除。

## 9. 无三角形饱和图的最后七种分布

由第 3–6 节，只剩 \(8\le k\le11\)。按 \(k=8,9,10,11\)，亏损和 11 的无序分布数为 \(3,2,1,1\)。\(J\) 是诱导 \(2K_2\)-自由、无三角形的饱和图。因此去掉孤立点后，\(J\) 要么是二分链图，要么为完全五环吹胀。二分情形可以把孤立的饱和点放到任意一侧，使得两侧各至多九点。这是因为两侧的非孤立点各至多九，全部饱和点不超过十五。将两侧按邻域大小排序，组间邻接矩阵在每行、每列均可取单调的 Ferrers 矩阵。五环情形可以固定五个锚点各代表一部，其他饱和点各归入五部之一或孤立点组，组间标记边恰由相应相邻部关系决定。对每个亏损分布，枚举二分侧大小及五环情形。总共 26 个公式。

每个公式使用这一分布给出的标记度数、宿主度至多九、至多五条未标记边、标记强团条件，以及 [现有 \(9/20\) 局部缺陷证书](../../regeneration_20261105/source_full/extracted/strong_clique/ore/order6_stability_045_exact_certificate.json) 的三角形上界。这里 \(m=98,\Delta=9\) 给
\[
\sum_v d_H(v)(9-d_H(v))+6T
\le \frac{2\cdot98(5\cdot9^2/4-98)}{(9/20)\cdot9}
<158.
\]
左侧为偶数，故至多 156。公式的 \(J\) 内无标记三角形，其他三元组使用三条标记位的合取计算三角形数。

另可加一个对任意点对 \(u,v\) 的必要约束。在 \(G-\{u,v\}\) 中，保留至少 \(98-18=80\) 条标记边，且剩余 21 个点全部仍有标记边。因为 \(k\ge8\) 时标记度最小至少五，删除两个点损失每点至多两条标记边。若删点后宿主最大度至多八，已有 \(5/4\) 界迫使恰有 80 条标记边且最大度恰八。\(9/20\) 缺陷式在此取等，迫使所有正标记度均为八，因而标记支撑只有 \(2\cdot80/8=20\) 个点，矛盾。所以任何 \(u,v\) 之外，必须有一个原宿主九度点，在 \(G\) 中不邻接 \(u,v\)。公式直接加入这一析取约束。

[生成器](d9_n23_trianglefree_sat.py) 对以上 26 个 CNF 输出精确 LRAT。每一例均已 RUP 重放通过。结合前面的归约，最大度至多九的简单图，其标记强团在支持集恰为 23 点时至多有 97 条边。若原强团有更多标记边且支持集恰 23 点，可先确认删掉标记边至 98 条是否仍保留全支持集。此处始终排除的是恰 98 条、23 点的假设；下面说明如何从此推出任意标记边数的同阶结论。

若 \(m>98\)，先在强团中选一集覆盖所有标记端点的边，每个端点选一条，得到至多 23 条。再由原强团任意加入标记边补到恰 98 条。所选子强团仍有全部 23 个支撑点，已经排除。

## 10. 固定证书的复现

饱和三角形的 8 份固定输入及 LRAT 证明在 [三角形模板](d9_n23_twin_sat)，无三角形饱和图的 26 份在 [链图与五环模板](d9_n23_trianglefree_sat)。[复现脚本](d9_verify_n23.py) 逐字节重建 CNF，与固定输入对照，核对 SHA-256 后独立重放整个 LRAT。[总核验记录](d9_n23_verified.json) 共复核 34 个实例及 4,727,741 条 RUP 添加。

~~~sh
python -B d9_n23_c5_saturated.py --maximum 7
python -B d9_n23_twin_triangle.py
python -B d9_verify_n23.py --jobs 2
~~~

Python 只使用标准库。第三个命令在 Windows 上使用已归档的 C 重放器。也可用 C17 编译器编译 `d7_rup_replay.c`，通过 `--checker` 指定可执行文件。重放固定附件不需要 SAT 求解器。证明的范围为 23 点标记支持的简单宿主，其他支持集大小需另行处理。
