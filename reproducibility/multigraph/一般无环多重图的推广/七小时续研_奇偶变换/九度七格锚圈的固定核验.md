# 九度七格锚圈的精确排除

设有限无环多重图最大度九，且有由 98 份标记构成的强团。若存在总余量至多 7 的全标记宿主诱导五环，则这样的强团不可能存在。

余量是奇数。[五格以内的组合证明](../七小时续研_组合归约/九度五格锚圈的精确界.md)给出 \(R\le5\) 的界。以下选择使旧核心最大的全标记诱导五环，并设其总余量为 7。由[一束归约](单一重复束的简单等号归约.md)、[九度旧归约](../delta9_parallel_reduction.md)和[十八束计数](九度十八束及十七束的一类组合排除.md)，每个重复束恰为双重，双重束数为 2 至 17。简单情况已有九度定理。标记端点至少 24 个，见[二十三点的完整排除](../七小时续研_有限度数/九度二十三点全部排除.md)。

五部大小满足 \(a_i=1+s_{i+2}+s_{i+3}\)。把余量向量按旋转及反射归为最小的字典序。共 38 种形状，其中 19 种由[相邻锚点对边容量](../三小时续研_组合归约/锚圈对边容量与奇偶界.md)及外部签名度界直接排除，3 种五个余量均正的形状由[纯组合证明](正余量小度数锚圈的纯组合排除.md)排除。

其余 16 种形状对标记三角形的有无各生成一个布尔公式。含标记三角形时，旧归约给标记端点至多 25 个。无标记三角形时，至少有七个未标记边端点，且由[临界阶数证明](无标记三角形的临界阶数.md)所用的干净点结构，全部无未标记邻接的顶点可二着色。每个形状的公式按端点对记录宿主、标记及第二份标记，约束按份数计的度、总标记 98 与强团见证。以 \(e_0=\sum_i a_i a_{i+1}\) 表示旧连续部底额、\(A=\sum_i a_i s_i\) 表示额外度容量，令 \(f\) 为两端均在外的标记份数，则 \(3f\le8R\)。因为每个外部标记的两端签名并须覆盖五环，而每个非空签名点至少花一份度在核心内。进一步，
\[
 98\le e_0+A-M-B_{\rm cut}-P+f.
\]
这里 \(M\) 为连续旧部纯蓝对数，\(B_{\rm cut}\) 为蓝割，\(P\) 为核心内部非底额标记份数。公式逐实例保留这些亏损。两端均在外的标记必须覆盖旧核心红边，故旧部中未被两端宿主邻接的各点数 \(z_i\) 满足 \(\sum_i z_i z_{i+1}\le M\)。公式通过枚举五个数的范围加入该点覆盖下界。选择标签时先按外点是否活跃及其锚邻接排序，再按宿主与标记矩阵取字典序最多者。

全部 32 个固定公式通过独立重建、哈希比对和正 RUP 重放，共核验 1,343,507 条添加。复现入口是本目录的 [布尔公式生成与核验器](d9_pentagon.py)。从多重图推广目录运行如下命令。

```powershell
$shapes = 's01033','s01105','s01114','s01123','s01132','s01204','s01213','s01222',
          's01231','s01303','s01312','s01402','s02023','s02113','s02122','s02203'
python -B 七小时续研_奇偶变换/d9_pentagon.py --bundles 0 --min-order 24 --select @shapes --out 七小时续研_奇偶变换/d9_r7_zero_triangle_free --strengthen --capacity-cuts --verify
python -B 七小时续研_奇偶变换/d9_pentagon.py --bundles 0 --triangles require --min-order 24 --max-order 25 --select @shapes --out 七小时续研_奇偶变换/d9_r7_zero_triangle --strengthen --capacity-cuts --verify
```
