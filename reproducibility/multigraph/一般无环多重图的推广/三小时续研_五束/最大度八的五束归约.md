# 最大度八恰五个双重标记束

按[最大度八归约](../delta8_parallel_reduction.md)，考虑最大度至多八、有恰好 81 份标记、至少 22 个标记端点的无环多重图强团。标记支撑无三角形，每个重复束恰有两份，且双重束组成匹配。这里处理恰有五个双重束的分支，故简单投影标记支撑大小为 \(s=76\)。

## 选取总余量至多八的锚圈

用简单投影的名义度上限 \(D=8\)。记 \(q_C\) 为全标记宿主诱导五环的标准归一化矩，\(L_R=q_C\mathbb E[R]/D\) 为其余量矩。可用全未标记边补足简单宿主度，且不改变任何全标记五环、旧部或按 \(D\) 算出的 \(R\)。投影亏损为 \(\delta=5/4-s/D^2=1/16\)。

[固定乘数](triangle_free_projection_3_2.json)给出
\[
 \delta \ge \gamma\left(L_R-\frac32q_C+\frac{3}{16}\right)-\epsilon,
\quad
\gamma=\frac{2168282759483523}{4768371582031250},\qquad
\epsilon=\frac{464458296643547}{250000000000000000000}.
\]
复验器沿用已核验的简单旗度等式及 Gram 系数。凡含全标记三角形的模式坐标均为零，因为三个红相邻位置的像互不相同。它逐阶从轨道表生成这 10,533 个坐标，在吸收负余量时跳过这些零坐标，其余坐标仍逐项用 \(0\le q\le1\) 补偿。每个外积权重及最后的亏损均以整数和有理数核验。

仍可使用[五环数量的组合上界](../多重图五阶旗精确上界.md)。简述如下。固定顶点 \(v\)，令 \(a\) 为它的不同标记邻点数。每个经过 \(v\) 的全标记诱导五环给出在 \(N_G[v]\) 外的一条标记边 \(xy\) 和两类不同的标记邻点。两类邻点分别标记到 \(x,y\)，且不见另一端。若这两类大小为 \(u,w\)，则环数上界取 \(uw\le a(u+w)/4\)。对 \(v\) 的每个固定标记邻点，提供某类位置的 \(xy\) 组成二部标记强团。在删去 \(N_G[v]\) 的宿主中，其 Ore 度至多 \(2D-a\)，因为 \(x,y\) 必合见 \(v\) 的每个标记邻点。用[二部标记 Ore 界](../二部标记见证亏损与邻域差.md)的 \(\beta=186/625\) 得经过 \(v\) 的环数至多 \(\beta a^2(2D-a)^2/4\)。逐点求和并用 \(u(2-u)^2\le32/27\) 对 \(0\le u\le1\)，得到
\[
q_C\le \frac{16}{27}\beta=\frac{992}{5625}.
\]

若每个锚圈的 \(R\ge10\)，则 \(L_R\ge(5/4)q_C\)。无锚圈时两矩均为零，亦有该式。因此
\[
\delta\ge
\gamma\left(\frac3{16}-\frac14\frac{992}{5625}\right)-\epsilon
>\frac1{16},
\]
矛盾。于是存在 \(R<10\) 的锚圈。因 \(R=40-2|B|\) 为偶数，故 \(R\le8\)。[半度余量计数](../多重图五环余量与锚点重数.md)已经排除 \(R\le4\) 的反例。

## 余量六和八的有限排除

按五环的旋转与反射选择代表，\(R=6\) 有 26 个旧部余量向量，\(R=8\) 有 36 个。每个旧部含其锚点，所以其大小至少一。对任意固定的余量向量，使用[五环对边容量](../三小时续研_组合归约/锚圈对边容量与奇偶界.md)中的
\[
 m\le 64+a_0a_2-s_3s_4+8(s_3+s_4)
\]
及其五种旋转。当右端小于 81 时，直接排除。如此分别排除 17、12 个向量。

其余 9、24 个向量沿用[旧五束固定证书](../d8_anchor_b5)。复验遵循每份证书记录的加强选项，重新生成完整 CNF，比对展开后固定输入的哈希，然后以正 RUP 重放固定 LRAT 行。新的封装只调用原归约，旧 CNF 的生成规则保持。

~~~text
python -B d8_five_anchored.py --verify --report d8_five_verified.json
~~~

报告中只有 \("unresolved": []\) 才表示本分支全部复验完毕。
