# 单一重复标记束的简单等号归约

设最大度 \(D\) 为奇数，取恰有 \(m=F(D)+1\) 份边的标记强团，其中 \(F(D)=D^2+\lfloor D/2\rfloor^2\)。当恰有一份额外的平行标记时，简单投影的标记端点对数为 \(F(D)\)。因此可以将[简单图取等检查](../../简单图的奇数最大度/anchored_odd_small.md)应用于该投影，同时保留多重宿主度约束。

## 取等回到图上的条件

在简单投影中选择旧核心最大的全标记宿主诱导五环，并将其余量向量在二面体对称下归到字典序最小的表示。投影和原多重宿主具有完全相同的双色端点对，故诱导五环、旧核心和名义度 \(D\) 下的余量都一致。

凡简单取等检查本身已经闭合的形状，投影的标记支撑只能为部大小 \((r,r,r+1,r+1,r)\) 的完整五环放大，\(r=(D-1)/2\)。其中每个标记端点对都接触一个简单宿主度恰为 \(D\) 的点，无法容纳额外标记份数。这也直接处理所有 \(D\ge17\) 的单一重复束情形。

用 \(\gamma_R=0.56425\)、\(\gamma_C=0.99999\) 和现有误差系数回放小度数取等检查，需单独再查的锚圈余量如下。

| \(D\) | 尚需检查的形状 |
| --- | --- |
| 9 | \((1,1,2,1,2)\) |
| 11 | \((1,1,2,1,2)\) |
| 13、15 | \((1,1,2,1,2)\)、\((1,1,3,1,3)\)、\((1,2,2,2,2)\) |

形状由[小度数取等检查程序](../../简单图的奇数最大度/check_anchored_odd_small.py)和[复算记录](单一重复束的简单投影等号形状.log)给出。九、十一度的余量七，以及十三度的余量九，均已由[正余量纯组合排除](正余量小度数锚圈的纯组合排除.md)解决。十三度和十五度的余量七由[半度加半格定理](../七小时续研_组合归约/半度再加半格的奇数精确界.md)解决。十五度的余量九由[九格的纯组合证明](../七小时续研_组合归约/十一度七格与十五度九格.md)解决。这闭合所有小奇数度的单一重复束情形。

## 九度

标记无三角形的分支已有[一束证明](../三小时续研_九度矩/九度无标记三角形的一束情形.md)。其余若有标记三角形，[九度归约](../delta9_parallel_reduction.md)及[二十三点排除](../七小时续研_有限度数/)把标记端点数限制为 24 或 25。按上表只需生成形状 \((1,1,2,1,2)\) 的一个布尔公式，同时使用任意两点删除后仍有宿主九度点的[删点引理](利用偶数取等结构的删点归约.md)及其简单投影版本。总标记份数固定为 98，额外平行份数为 1。在强团约束中标记按端点对计，在宿主度约束中按实例计。公式的不可满足证书已经逐行重放通过，共 211,080 条正 RUP 添加。由此九度的整个单一重复束分支闭合。

在多重图推广目录下，以带断言的 Python 运行以下命令可重新生成公式、核对展开后哈希并重放证书。

```text
python -B 七小时续研_奇偶变换/d9_pentagon.py --degree 9 --bundles 1 --triangles require --min-order 24 --max-order 25 --select s11212 --out 七小时续研_奇偶变换/d9_b1_triangle --strengthen --verify
```

固定输入及证书见[重放记录](d9_b1_triangle/s11212.json)所在目录。

## 十一度的独立公式

唯一形状仍为 \((1,1,2,1,2)\)，有 24 个旧核心点，标记端点总数至少 \(\lceil 2\cdot147/11\rceil=27\)。核心外不同锚邻接不超过 7。每个零签名的标记邻居至少三签名，因此可补到 \(7+(11-5)\lfloor 7/3\rfloor=19\) 个外部位置。宿主度上限为 11，保留标记三角形的可能。固定公式和证书通过哈希复核及 1,413,953 条正 RUP 添加重放。

```text
python -B 七小时续研_奇偶变换/d9_pentagon.py --degree 11 --bundles 1 --triangles allow --min-order 27 --select s11212 --out 七小时续研_奇偶变换/d11_b1 --strengthen --verify
```
