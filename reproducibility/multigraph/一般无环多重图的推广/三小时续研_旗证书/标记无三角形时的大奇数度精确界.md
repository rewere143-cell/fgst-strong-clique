# 标记支撑无三角形时的大奇数度精确界

设 \(D\ge10^{36}\) 为奇数。有限无环多重图有度上限 \(D\)，其标记强团大小为 \(m\)。若标记支撑不含红三角形，则
\[
m\le D^2+\left\lfloor D/2\right\rfloor^2 .
\]
按五环顺序取部大小 \((D-1)/2,(D-1)/2,(D+1)/2,(D+1)/2,(D-1)/2\)，标记全部连续部边，即达到等号。

令 \(\delta=10^{-36}\)，\(M=m/D^2\)，\(S=s/D^2\)，\(e=(m-s)/m\)。反设 \(m>D^2+\lfloor D/2\rfloor^2\)，则 \(M>5/4-\delta\)。如宿主实际度较低，可以添加互不相连的全蓝星恢复度上限 \(D\)。由[显式半度临界判据](../三小时续研_组合归约/显式半度临界余量判据.md)，每个全红宿主诱导五环均有 \(R/D>1/2\)。于是[半度条件证书](conditional_half_certificate.json)给出 \(S\le1.22181\)，因而 \(e>.0225\)。[统一上界](README.md)给 \(M<1.28574\)。

原[大额外份额证明](../多重图五阶旗精确上界.md)已经给出 \(e<.22\)，因为 \(M>5/4-\delta>1.249\)。该文中五份旧对偶证书覆盖 \([.2105,.225]\)。下面证明它们在质量下端放宽 \(\delta\) 后仍有效，于是 \(e<.2105\)。同样的容差证明适用于[红三角形质量证书](rank6_triangle_density.json)，其结论仍有 \(Z>7/500\)，与红三角形不存在矛盾。

## 固定对偶的有限容差

只需允许 \(5/4-\delta\le M<5/4\)，而在 \(M\ge5/4\) 时原行已适用。固定各证书的整数系数。原证明中的等式只使用有限旗的归一化和度数，全部仍成立。以下枚举其依赖质量下端的线性行和矩块，并给出下端放宽后产生的误差。

1. 在五阶基础部分，平行度的上界系数 \(f(M)=M-M^2/2\) 增量至多 \(\delta/4\)，因为该区间上 \(|f'(M)|\le1/4\)。两个质量上下端仍只改变独立抽边的质量下界 \(2M\ge5/2\)。每个归一化的基础类型计数 \(|\operatorname{Aut}(F,T)|X(F,T)\le1\)，由包含森林的一棵生成树求和得到。因此这些线性行的正误差至多 \(2\delta\)。依赖质量端点选择切点的切线行来自二次函数的全局切线上界，原切线仍有效。
2. 五阶类别矩下方的质量界用到的 \(1/M\) 与 \(4/5\) 的差至多 \(\delta\)。旧证书中的额外抽边类别矩若用到平行份数上界，只有左上角协方差子块乘以 \(2\min(f(M_{\rm lo}),e_{\rm hi}M_{\rm hi})\)。把下端从 \(5/4\) 换成 \(5/4-\delta\) 使这个乘数最多增加 \(\delta/2\)。任一协方差子块原始条目归一化后至多为 4，因为每个延伸变量的计数除以 \(D\) 至多为 2。矩块修正每个条目至多 \(2\delta\)。其他矩块与质量下端无关。
3. 在六阶模型中，原放宽下端对简单份数 \(S\ge (1-e_{\rm hi})M_{\rm lo}\) 的独立抽边行产生至多 \(2\delta\) 误差。支持上界及锚圈下界 \(R/D\ge1/2\) 已由前面的独立估计给定。对 \(\rho=R/D\)、\(j=J/D\)，原一般锚圈式给 \(2j-\rho\le4\delta\)。强化行的旧界为 \(j\le \rho-1/2\)。在 \(1/2\le\rho\le1\) 时，[半度放电的强化式](README.md)给 \(j\le\rho-1/2+2\delta/\rho\le\rho-1/2+4\delta\)。在 \(\rho>1\) 时由一般式也得同一放宽界。六阶的红团行 \(J_A/D\le k-(k-1)M_{\rm lo}\) 放宽 \((k-1)\delta\)。每条行所乘的锚圈或红团父模式至多是保留坐标之和乘以 10，各坐标至多 1，共 31,073 个。对单一标记数固定的锚圈父模式，更直接地至多有 \(\binom5k\le10\) 个标签选择，从而锚圈行的误差至多 \(4\delta\cdot10\cdot10\)。红团父模式各以系数 1 求和，误差至多 \(3\delta\cdot31073\)。六阶余下约束与质量下端无关。这里全红 \(K_5\) 可以由无红三角形直接排除。事实上精确度数式 \(4m\le5D(D-1)-20\) 在任一奇数度反例中也排除全红 \(K_5\)，所以同一结论 \(Z>7/500\) 对有红三角形的奇数度反例也适用。

因此，证书族的每条归一化线性不等式的正误差至多 \(10^6\delta\)，每个需要修正的矩条目绝对误差同样至多 \(10^6\delta\)。设 \(\mu_i\ge0\) 是实际线性乘数，各个外积因子为 \(v_{j}\)。线性误差增加至多 \(10^6\delta\sum_i\mu_i\)，在任一矩的外积 \(v_jv_j^{\mathsf T}\) 上的误差增加至多 \(10^6\delta\|v_j\|_1^2\)。不改变原负残差补偿，其所用份额区间和树上界仍适用。只须在旧对偶右值上加
\[
10^6\delta\left(\sum_i\mu_i+\sum_j\|v_j\|_1^2\right).
\]
[精确容差程序](replay_odd_triangle_continuity.py)对五份区间证书、一份红三角形质量证书复验后添加此项。三条质量上界仍严格小于 \(5/4-\delta\)，两条不可行证书仍严格为负，最后一条 \(-Z\) 的上界仍小于 \(-7/500\)。所有数值比较使用有理运算，完整右值见[复验输出](replay_odd_triangle_continuity.log)。

在本子目录可用

```powershell
python -B replay_odd_triangle_continuity.py
```

复验，可加 `--vendor <依赖目录>`。
