# 二十三点五条蓝边的链图模板

沿用[蓝端点链归约](二十三点无标记三角形的蓝端点链归约.md)及[八蓝端点纯排除](二十三点无标记三角形的八蓝端点排除.md)的记号。任一仍可能的二十三点九度、98 份标记、标记无三角形的候选有五条蓝边、蓝端点数 \(k=9\) 或 10。总宿主度亏损为一，因而每个孤立的干净点标记度至少八；若干净点孤立集大小为 \(i\)，它们合计至少 \(9i-1\) 份标记。干净点链图非平凡分量两侧大小 \(a\le c\le9\)，设 \(m_U=e_H(U)\)。有
\[
 m_U\ge108-9k,\qquad ac\ge m_U.
\]
若 \(B\) 点标记到干净孤立点，则其在分量中必须完整标记邻接一整侧。若某侧有 \(s\) 个这样的关联 \(B\) 点，则它们给孤立点的容量按点至多 \(8-\text{侧大小}\)，且 \(m_U\le(\text{侧大小})(9-s)\)。同时，单个 \(B\) 点至一个干净孤立点最多两份标记，总计至少有 \(d_H(z)-2\) 个不同标记邻点，因为每点额外平行度至多二。

## 九个蓝端点

蓝图必为一个两边路径加三个单边。\(U\) 有十四点，\(m_U\ge27\)，乘积条件给 \(i\le3\)。

若 \(i=3\)，两侧共十一点。 \((4,7)\) 时，至少六个 \(B\) 点须连四点侧，因为孤立点需 26 份标记，九个 \(B\) 点每个从七点侧型贡献至多一份、四点侧型至多四份。于是 \(m_U\le4(9-6)=12\)。\((5,6)\) 时，侧型容量分别三份、两份，同式至少八点连五点侧，\(m_U\le5\)。其它两侧大小乘积不足 27。

若 \(i=2\)，两侧共十二点。 \((3,9)\) 或 \((4,8)\) 只有小侧可用；每个 \(B\) 点对两个孤立点至多四份，至少五个 \(B\) 点关联小侧，使 \(m_U\le4(9-5)=16\)。\((5,7)\) 时两侧关联容量分别三、一，至少四点连五点侧，使 \(m_U\le25\)。\((6,6)\) 时两侧每点至多贡献二份，至少九个 \(B\) 点关联，其中一个六点侧至少五个，\(m_U\le24\)。

若 \(i=1\)，唯一孤立点 \(z\) 需至少八份标记、至少六个不同邻点。 \((4,9)\)、\((5,8)\) 只有小侧可用，立即使 \(m_U\le 5(9-6)=15\)。对 \((6,7)\)，设有 \(s,t\) 个邻接 \(z\) 的 \(B\) 点分别完整邻接两侧。\(s+t\ge6\)，由 \(m_U\ge27\) 有 \(s\le4,t\le5\)。若 \(s=1\)，只有该一点可向 \(z\) 加一份重复（七点侧型无容量重复），合计至多 \(1+5+1=7\)；若 \(t\le1\)，则 \(s+t\le5\)，同样不行。故 \(s,t\ge2\)，从而 \(st\ge8\)。七点侧型各有一份去 \(z\) 的标记和一份蓝度，已满宿主度，所以两类之间的宿主邻接只能为蓝，无法覆盖所有 \(st\) 对。取两个异类不邻接点，比较各自向任意一对 \(A,C\) 的规定标记，迫使 \(A,C\) 间全邻接。这又要求 \(s\le2,t\le3\)，矛盾。

故 \(i=0\)，两侧大小只能为 \((5,9),(6,8),(7,7)\)。

## 十个蓝端点

蓝图为五条互不相接的单边，每个 \(B\) 点恰一份蓝度。\(U\) 有十三点，\(m_U\ge18\)，乘积条件给 \(i\le4\)。

若 \(i=4\)，两侧共九点，只有 \((3,6),(4,5)\)；孤立点至少需 35 份标记。前者小侧型容量为五、大侧型二，至少五个 \(B\) 点关联三点侧，使 \(m_U\le12\)。后者小侧型容量四、大侧型三，也至少五点关联四点侧，使 \(m_U\le16\)。

若 \(i=3\)，两侧共十点。 \((3,7)\) 时两侧型容量五和一，孤立点至少需 26 份标记，使至少四点关联三点侧，\(m_U\le15\)。其它可能为 \((4,6),(5,5)\)。

若 \(i=2\)，两侧共十一点。 \((2,9),(3,8)\) 只有小侧能供给标记，每个 \(B\) 点至两孤立点最多四份，至少五个关联小侧，使 \(m_U\le 3(9-5)=12\)。其它可能为 \((4,7),(5,6)\)。

若 \(i=1\)，唯一孤立点 \(z\) 至少六个不同标记邻点，且总标记度至少八。 \((3,9),(4,8)\) 仅小侧型可，故 \(m_U\le12\)。剩下 \((5,7),(6,6)\)。记 \(s,t\) 为邻接 \(z\) 的两侧型人数。若全部是五点侧型，\(m_U\le5(9-6)=15\)；若全部七点侧型，则每点只能给一份 \(z\) 标记，至少八点关联，\(m_U\le7\)。若两侧都六点且只一类，必须恰六点关联、\(m_U=18\)，另侧六点至少还有 \(54-18-1=35\) 份去 \(B\) 的标记，但关联 \(z\) 的六点不能见另侧，余四点仅至多 32 份。

故两类都出现。在 \((5,7)\) 下，七点侧型有一份到 \(z\) 的标记及一份蓝度，已满度，两类间只能用匹配蓝边相连，无法全部 \(st\) 对相连。在 \((6,6)\) 下，两类各点都有六份至其侧、至少一份至 \(z\) 的标记和恰一份蓝度，故至对方类至多有两个宿主邻点；若两类间总相邻，则 \(s,t\le2\)，也不行。故有异型不邻接的一对点，迫使两侧宿主完全二部，因而 \(s\le9-c,t\le9-a\)。因 \(s+t\ge6\) 和 \(a+c=12\)，必两式均等，且 \(s+t=6\)。两个干净侧因与这六点的规定单份标记全部满度。\(z\) 的六邻点提供恰八份标记，已用唯一宿主度亏损。六关联点合计标记容量 48，去 \(U\) 用了 \(sa+tc+8\)，在 \((5,7),(6,6)\) 情形分别等于 46、44，只余二或四。其余四个 \(B\) 点皆满九份宿主度且有一份蓝度，但没有 \(U\) 邻点。它们之间也不能标记，否则无法见证任意 \(U\) 内标记。因此其 32 份标记只能去六关联点，容量不足。

顺次得剩余模板如下。

| 蓝端点数 | 干净孤立点数 | 非平凡分量的两侧大小 |
|---:|---:|---|
| 9 | 0 | \((5,9),(6,8),(7,7)\) |
| 10 | 0 | \((4,9),(5,8),(6,7)\) |
| 10 | 2 | \((4,7),(5,6)\) |
| 10 | 3 | \((4,6),(5,5)\) |

## 精确编码及重放

[生成器](d9_order23_blue_chain_sat.py)把蓝边的各同构形状固定。对八个蓝端点，有四边匹配、三叶星加二单边、三边路径加二单边、两个两边路径加一单边；对九及十端点形状如上。干净点链图分量的两侧同时排列，使邻接矩阵的每行、每列向左、向上闭合，含首行、首列的通用点。孤立点每条标记还要求其对端完整见某侧。所有非蓝邻接必须标记，标记边对可再增加一份平行标记，但重复束只接触蓝端点，且每束两根至少 13 个不同根外宿主邻点。全局强团、无标记三角形、顶点度容量、标记总亏损及八度删除条件均逐条编码。对固定蓝图的置换轨道选择字典序极大者，保留每个同构类。

从本目录令父目录进入 Python 模块路径后，可用以下命令重放已闭合组。生成器核对固定 CNF、LRAT 的 SHA-256 并用独立的正 RUP 重放器验证。未决形状不可选入重放命令。

```powershell
$env:PYTHONPATH = Split-Path -Parent (Get-Location)
python .\d9_order23_blue_chain_sat.py --out d9_order23_blue_chain --verify --shape matching star path twopaths path9 matching10
```
