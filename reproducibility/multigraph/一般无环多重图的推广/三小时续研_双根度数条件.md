# 一根与双根覆盖的度数条件

设 (G\) 是有限无环多重图，(D=\Delta(G)>0\)。设 (H\) 为强团的标记边集，度数和边数均按实例计。写 (M=e(H)/D^2\)。取最大标记度点 (x\)，再取它的标记邻点中标记度最大的 (y\)。写 (a=d_H(x)/D,b=d_H(y)/D\)，并以 (p,q\) 表示这两点的不同标记邻点数除以 (D\)。若标记集为空，结论自动成立。以下有 (0\le p\le a\le1\) 和 (0\le q\le b\le a\)。

**结论。** 如果 (a\le 43/50\)，或全图每点的不同标记邻点数至多 (83D/100\)，或 (p+q\le33/20\)，则
\[
 M\le\frac{1249}{1000}.
\]
这给出上述情形的统一界。(D\) 为奇数且 (D\ge501\) 时，它也推出 (e(H)\le D^2+\lfloor D/2\rfloor^2\)。

## 一根与两根约束

取 [二部标记见证界](二部标记见证亏损与邻域差.md) 的 (\beta=186/625\)，以及 [一般 Ore 度归约](多重图两级余量计数.md) 的 (\alpha=(1+\beta)/4\)。记
\[
 X=a(2-a-b+q)+pb,\qquad K=a(1-a)+pb.
\]
[换根容量计数](多重图换根余量强化.md) 式 (1) 取 (h=a\) 并舍去非负亏损项，推出
\[
 M\le X,\qquad
 2M\le X+\min\{\beta(2-q)^2,K\}+\beta(2-p)^2.
\]

再以 (G'=G-N_G[x]\) 表示删除 (x\) 及所有宿主邻点后的诱导子图。凡不在 (G'\) 内的标记边，必接触 (x\) 的某个宿主邻点。若该边接触 (x\)，它自己的另一端就是不同标记邻点。(x\) 的 (pD\) 个不同标记邻点中每点标记度至多 (bD\)。其余宿主邻点至多 ((1-a)D\) 个，每点标记度至多 (aD\)，所以这部分共至多 (KD^2\) 份标记。

对每条仍在 (G'\) 中的标记边 (uv\)，与 (x\) 的每条标记邻接 (xz\) 比较，(u,v\) 至少有一端邻接 (z\)，因为 (x\) 此时不邻接 (u,v\)。这使两端在 (G'\) 的加权度数之和比在 (G\) 至少少 (pD\)，即 (\sigma_{G'}(H\cap G')\le(2-p)D\)。一般 Ore 度界给出
\[
 M\le K+\alpha(2-p)^2.
\]

## 有理区间核验

复验 [四变量区间程序](三小时续研_双根区间核验.py)。对每个区间盒，将 (b,p\) 的上端截在 (a\) 的上端、将 (q\) 的上端截在 (b\) 的上端，再按必要条件提高 (b,a\) 的下端。(K\) 中的二次项 (a(1-a)\) 在区间中最靠近 (1/2\) 的点取最大值。对 (X=a(2-a)+aq+(p-a)b\)，程序分别用 (aq+(p-a)b\le pq\) 和盒端点估计，取二者的较小值。各 Ore 部分取 (p,q\) 的下端以获得安全上界。若三个 (M\) 上界中的最小值仍超过目标，沿最长边平分该盒。仅在 (p+q\) 下端大于分支阈值时舍去该盒。

~~~powershell
python -B 三小时续研_双根区间核验.py
~~~

三项核验分别结束于 98,893、348,185、1,317,481 个访问盒，均无未决盒。
