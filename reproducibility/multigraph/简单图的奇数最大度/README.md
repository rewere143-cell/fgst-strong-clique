# 简单图的奇数最大度

对最大度为正奇数 $D$ 的有限简单图，强团最大大小恰为 $(5D^2-2D+1)/4$。五环膨胀构造给出取等。

- [完整定理、取等构造及分段证明](简单图奇数最大度的精确强团界.md)。
- [固定复现卷](简单图奇数度_固定复现_2026-11-16.zip)及[独立解压复验记录](简单图奇数度_独立复验/summary.json)。
- [新版原稿的输入比对](source_comparison.json)及[原稿复跑记录](新版论文复跑/summary.json)。
- [最大度七的有限证书](degree-seven-simple.md)及[最大度九的独立有限证明](最大度九简单图锐界.md)。

完整复验请先解压固定卷，再在解压目录运行 `python -B verify_odd_archive.py --output 复验输出`。若只在本目录核验奇数度的有理矩和整数门槛，可运行 `python -B verify_odd_simple.py`。
