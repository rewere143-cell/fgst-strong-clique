# 一般无环多重图的六阶逐步上界

设 \(D>0\) 为有限无环多重图的最大度，\(m\) 为强团的标记边实例数，\(s\) 为其中不同端点对数。令 \(M=m/D^2\)、\(S=s/D^2\)、\(e=(m-s)/m\)。

**统一锐界。** 对所有有限无环多重图，\(m\le5D^2/4\)。偶数 \(D\) 时此界由平衡五环吹胀取到。此结论对含有红三角形的标记支撑同样成立。

奇数 \(D\ge10^{36}\) 时，同一个有理对偶的有限容差还给出 \(m\le D^2+\lfloor D/2\rfloor^2\)，见[一般多重图大奇数度锐界](一般多重图大奇数度锐界.md)。

以下区间排除仅在严格违反 \(M\le5/4\) 的分支中使用。最早起点为[五阶统一界](README.md)所证 \(M<1.284919\)，而 \(M>5/4\) 时的份额 \(e<.2105\) 来自[原精确上界](../多重图五阶旗精确上界.md)。第一个六阶阶段详见[初次六阶排除](一般多重图六阶上界1283.md)。

末行的区间覆盖尤其直接。若 \(M>5/4\)，半度放电给每个红色宿主诱导五环 \(R/D>1/2\)。简单投影由此给 \(S\le1.22181\)，故 \(e>1-1.22181/(5/4)>.0225\)。该思路也包括没有红色宿主诱导五环的图。已证的 \(M<1.274\)、\(e<.2105\) 给出另两端。末行有理右值小于 \(5/4\)，与严格违界假设矛盾。在这一步，红三角形坐标及其延伸全部参与模型，只有含有全红 \(K_5\) 的坐标被固定为零。

## 后续步骤的强锚圈约束

后续采用[锚圈内外联立容量](../三小时续研_联立五环内外容量.md)给定的更强局部式。若 \(r=R/D\in[1/2,1]\)、\(j=J/D\)、\(g=M-5/4\)，且 \(f\) 是连续核心部之间纯蓝端点对数除以 \(D^2\)，则
\[
2g+2f\le \frac{1+r}{2+r}r(r-1/2)-\frac{1+r^2}{2+r}\,j .
\]
令 \(g_0=M_{\rm lo}-5/4\)。将第一项的单调反函数以向下取整步长 \(10^{-4}\) 得到 \(\alpha\)，于是 \(r\ge\alpha\)。由于 \(f\ge0\)，还可用
\[
j\le f_{g_0}(r)
  :=r+\tfrac12-\frac{(\tfrac32+2g_0)r+(\tfrac12+4g_0)}{1+r^2}
\qquad(\alpha\le r\le1).
\]
\(f_{g_0}\) 在该区间凸：二阶导数的符号取决于
\(
(\tfrac32+2g_0)r(3-r^2)+(\tfrac12+4g_0)(1-3r^2)
\)，
前一因子 \(r(3-r^2)\ge11/8\)，后一因子 \(1-3r^2\ge-2\)，对归档 \(g_0\) 即得非负。程序取在 \(\alpha\) 处为 \(f_{g_0}(\alpha)\)、在 1 处放宽为 \(1/2-2g_0\) 的割线。其斜率至少 \(1/2\)，因此在 \(r>1\) 时也支配一般锚圈式 \(j\le r/2-2g_0\)。分别将斜率向上、截距的减项向下取有理网格，使系数闭包保持这个上界。

此外，使用[红三角形签名行](红三角形签名旗行.md)第 2 版。没有要求标记支撑无三角形。与全红 \(K_5\) 相关的坐标仍由前序已证明的度数式为零。

## 复验

在本子目录运行

```powershell
python -B verify_shadow_chain.py
```

可加 `--vendor <依赖目录>`。程序重建并核对每份五、六阶证书的模型哈希，同时核验区间衔接与份额先验。所有对偶右值已包含有理残差补偿。完整运行见 [shadow_chain_uniform_sharp_replay.log](shadow_chain_uniform_sharp_replay.log)。可用 `audit_shadow_scale.py <证书文件>` 带整数溢出保护单独复验，末步原始输出见 [rank6_uniform_sharp_125_replay.log](rank6_uniform_sharp_125_replay.log)。
