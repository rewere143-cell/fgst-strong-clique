# 排除九度的全部二十三点候选

设规范化无环多重宿主最大度至多九，标记强团有 98 份，且标记支持恰二十三点。没有重复标记的情形由简单图九度锐界覆盖。现设至少有一个重复标记束。上一轮已排除[无标记三角形情形](../三小时续研_有限度数/二十三点无标记三角形的五蓝边精确模板.md)。以下排除有标记三角形，使用[新增的全图干净链归约](九度红三角形与无蓝端点链图.md)。

令蓝边数为 \(\beta\)，蓝端点集 \(B\) 大小为 \(k\)，无蓝端点集为 \(U\)。标记度总亏损 \(9\cdot23-196=11\)，故 \(1\le\beta\le5\)，且 \(U\) 的标记亏损至多 \(11-2\beta\)。\(G[U]\) 简单，且
\[
e_H(U)\ge98-9k+2\beta>0.
\]
其唯一非平凡分量为链图，取两侧大小 \(a\le c\le9\)，余下孤立点数 \(i=23-k-a-c\)。设 \(b_0=98-9k+2\beta\)，则 \(ac\ge b_0\)。

若某蓝端点 \(x\) 标记邻接一个干净孤立点，必须由其在链分量的宿主邻域覆盖链的所有标记。设该链的最小点覆盖大小为 \(\tau\)。一侧覆盖必须取该侧的全部点；若取 \(r<a,s<c\) 个两侧点，则 \(r,s\ge1\)，无覆盖的 \((a-r)(c-s)\) 对端点不得有边，因此必须 \(ac-(a-r)(c-s)\ge b_0\)。按此得到整数下界 \(\tau_0\le\tau\)。对于任一蓝端点 \(x\)，记蓝度为 \(b_x\)，则它向干净孤立点的标记份数至多
\[
\max(0,\min(9-b_x-\tau_0,\;2i,\;i+2)).
\]
这里 \(2i\) 用每束最多双重，\(i+2\) 用每点额外平行度至多二。对所有 \(B\) 点求和至少需要 \(9i-(11-2\beta)\) 份。按该必要条件筛选全部蓝图及尺寸。

## 蓝图枚举和公式

[生成器](d9_blue_ferrers_sat.py)对一个至多五条边的连通蓝分量，依次枚举点数 \(2\) 至边数加一及该边数的所有简单图，保留连通者，再按度数相同的点置换取规范边表。对同总边数的蓝图按连通分量类型的多重集枚举。对每个蓝图再遍历 \(a,c,i\)，实施上述容量判定。总计如下。

| 蓝边数 \(\beta\) | 固定蓝图与干净链尺寸的必要形状数 |
|---:|---:|
| 1 或 2 | 0 |
| 3 | 4 |
| 4 | 21 |
| 5 | 87 |
| 合计 | 112 |

固定形状后，干净链两侧同时按包含关系排好，使二部邻接矩阵向左、向上闭合，首行、首列为通用点。其余非蓝宿主邻接均须标记。给每个标记对另设可选布尔双重份数，约束宿主度、总亏损和重复支撑。任意两条不交的标记边至少有一个跨端点宿主邻接。对于每个标记端点对，其不同根外邻点不少于十一，因为除根束外的标记都有该邻域的端点；十个此类点至多容纳 \(10\cdot9+2<98\) 份。重复束加强到十三点，来自[既有归约](../delta9_parallel_reduction.md)。任意两点不能支配全部九度宿主点，见[两点删除引理](奇数度等号与两点删除.md)。

三角形条件来自[零点模板排除](../三小时续研_有限度数/二十三点三角形的零点容量与精确重放.md)与[根蓝辐条归约](../三小时续研_有限度数/二十三点三角形的根蓝辐条归约.md)。每个标记三角形支配整个支持、三邻点为空、最多一个双邻点、根蓝辐条为一至三条、简单宿主根度至少八且至多一个根仅八度，并且三角内部边单份。因为蓝图已固定，潜在标记三角形的根蓝辐条数由这三点的蓝度和确定。公式要求至少有一个这样的标记三角形。对蓝图自同构及干净链的相同邻域点换标号，选择字典序极大者，至少保留每个允许轨道中的一个标号。

112 个固定 CNF 全由独立正 RUP 核验排除。复跑重新生成公式，核对展开的 CNF 与 LRAT 的 SHA-256，随后重放 8,183,267 条添加记录及 11,108,407 条删除记录。[复跑输出](chain_n23_replay.log)

~~~powershell
python -B .\d9_blue_ferrers_sat.py --out chain_n23_broad --verify --jobs 1
~~~

至此连同既有无标记三角形的证明，最大度九且标记支撑恰二十三点的反例全部排除。
