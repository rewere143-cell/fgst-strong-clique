# Faudree–Gyárfás–Schelp–Tuza 强团猜想的简单图奇数度情形

## 定理

设 \(D\) 为正奇数。有限简单图中，最大度为 \(D\) 时的最大可能强团大小恰为
\[
F(D)=\frac{5D^2-2D+1}{4}.
\]
这里强团指一组边，其中任意两条边共享端点，或各有一个端点在宿主中相邻。等价地，它们在平方线图中构成团。

## 达到上界的构造

令 \(D=2r+1\)。将五环的五个顶点依次替换成大小为 \((r,r,r+1,r+1,r)\) 的独立集，在对应于五环边的部对之间加入全部边。各部点的度数为其两相邻部的大小之和，最大值为 \(2r+1\)。任意两个五环边型共享一部或有一条五环边连接其端部，故构造的整个边集为强团。边数为
\[
r^2+r(r+1)+(r+1)^2+(r+1)r+r^2
=5r^2+4r+1=F(2r+1).
\]
当 \(D=1\) 时，构造是一条边。

## 上界证明

设 \(H\) 为任意简单宿主中的标记强团，记 \(m=|E(H)|\)。反设 \(m>F(D)\)。由于 \(m\) 为整数，写 \(t=D/2\)、\(d=5D^2/4-m\)，则
\[
m\ge F(D)+1,\qquad d\le t-\frac54 .
\]
最大度一的宿主是匹配，强团至多一条边。对其余度数，使用下表覆盖全部奇数。各行均使用同一强团定义和度数参数 \(D\)。

| 奇数 \(D\) | 证明 |
| --- | --- |
| \(3\le D\le33\) | 用诱导全标记五环的有理矩选取锚圈。枚举其整数余量、扩大模板和可行外部标记，排除 \(d\le t-5/4\)。[组合推导及有限检查](anchored_odd_small.md) |
| \(35\le D\le149\) | 按各外点的实际锚点邻接型给旧核心缺失对和外部标记收费，逐度排除反例。[邻接型计数](anchored_odd_signature.md) |
| \(151\le D\le49999\) | 由五环数量与锚点缺口两项矩证书控制初始余量，再用五部覆盖、扩大模板和容量收费导出精确上界。[锚定证明](anchored_odd_bound.md) |
| \(D\ge50000\) | 简单宿主中 \(s=m\)。反设给 \(s/D^2>5/4-1/(2D)\ge5/4-10^{-5}\)。两轮核心归并定理遂给 \(m\le F(D)\)。[大度数归并定理](two_stage_odd.md) |

用到的有限同态矩来自三色宿主模式。对固定标记根及添点模式，除以标记根数和相应的 \(D\) 的幂。度数恒等式由有限正则化给出，半正定项是逐固定根映射的有理秩一外积之和。精确复核器从固定模式输入重建系数，验证五环丰度、锚点缺口及 \(9/20\) 局部缺陷罚项。证明的其余部分为组合计数和有界整数核验。[有限同态矩说明](source_snapshot/reproducibility/finite_homomorphism_certificate_proof.md) · [局部缺陷证书](局部缺陷证书.md)

## 固定版复验

在固定复现卷解压后的目录运行

```powershell
python -B verify_odd_archive.py --output 复验输出
```

需要 64 位 Python 3.9 或更新版、C17 编译器和小端环境。可用 `--cc` 指定编译器。程序先核对复现卷中每个文件的 SHA-256，再重建原稿的模式索引、度数及 Gram 系数，最后精确核验用于奇数度的四段证明。结果写入另一个目录。固定输入的复验只使用 Python 标准库及 C17 编译器。

本定理的宿主范围是有限简单图。它给出奇数最大度的精确上界与取等构造，证明保留有理旗代数证书和有限整数核验。
