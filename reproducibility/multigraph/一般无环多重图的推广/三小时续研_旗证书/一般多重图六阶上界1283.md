# 一般无环多重图的小于 \(1.283D^2\) 上界

在有限无环多重图中，设 \(D>0\) 为最大度，\(m\) 为标记强团的边实例数，\(s\) 为其中不同的端点对数。令 \(M=m/D^2\)、\(S=s/D^2\)、\(e=(m-s)/m\)。本证书给出
\[
M<\frac{1283}{1000}.
\]

## 区间先验

反设 \(M\ge1283/1000\)。由[前序五阶证明](README.md)，\(M<1.284919<32123/25000\)，且 \(e<421/2000\)。对任一全红宿主诱导五环，五阶证明第 1 节给 \(R/D\ge1521/2500\)。[简单投影](half_anchor_projection.py)使用归档的丰度、锚点和两个条件余量证书，在此下界给出 \(S\le1.21729\)，从而
\[
e\ge 1-\frac{1.21729}{1.283}>\frac{51}{1000}.
\]
所以第五、六阶复验使用的闭区间
\[
(M,e)\in[1283/1000,32123/25000]\times[51/1000,421/2000]
\]
包含反设分支。

## 六阶对偶

[固定证书](rank6_uniform_1283_exclusion.json)保留五阶全部坐标、选定六阶坐标和 48 个六阶无标签矩块。全红 \(K_5\) 及其延伸坐标由[红团度数界](README.md#3-红团的重复度限制和共邻点不等式)为零，先固定后删去，共删去 27 个坐标。还使用了[外积矩与五环余量的六阶行](half_anchor_shadow.py)、红团重复度、局部蓝度损失和公共红邻域行。所有这些行均保有归档有限图归一化。

新增六阶组容量由[五阶证明的生成树计数](../多重图五阶旗精确上界.md)在 \(n=6\) 直接给出。若 \(k=0\)，根类别是首份标记端点对；若 \(k>0\)，根类别是任一额外森林标签。指定有序根边 \((0,1)\)，含根边的生成树有 \(2n^{n-3}\) 棵，分别选择其余 \(k-1\) 条标签边。每棵树有至多当前根归一化质量的加权延伸数。除以 \((n-2)!\) 和可选有向根数 \(2\max(1,k)\)，给出一致的阶 \(n\)、标签数 \(k\) 组上界。选取而未使用的六阶图案不会增加原模型的组和，故该容量对本证书的删减坐标仍适用。

精确吸收全部负残差后，复验器输出
\[
M\le \frac{955895238057484377539985707}{750000000000000000000000000}
=1.2745269840766458\ldots <1.283
\]
于上述闭区间，矛盾。分式是此分支的排除右值，总体结论是 \(M<1.283\)。

## 复验

在本子目录运行

```powershell
python -B half_anchor_projection.py --mass-low 1283/1000 --direct-certificate conditional_half_certificate.json --direct-gamma 45119/100000
python -B half_anchor_shadow.py rank6_uniform_1283_exclusion.json --replay
```

第二条可加 `--vendor <依赖目录>`。原始精确输出存于 [rank6_uniform_1283_replay.log](rank6_uniform_1283_replay.log)。根据[前序五阶证明](README.md)第 4 节可依次核验质量上端。使用原[高额外份额证明](../多重图五阶旗精确上界.md)可核验 \(e<421/2000\)。
