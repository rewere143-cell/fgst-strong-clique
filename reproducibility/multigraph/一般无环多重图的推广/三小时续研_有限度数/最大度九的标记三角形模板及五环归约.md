# 九度标记三角形的有限模板与八度删除条件

设无环宿主 \(G\) 的最大度不超过九，强团 \(H\) 有 98 份标记边，且至少有一个重复标记束。只保留标记端点，并对每个标记束仅保留其标记实例、对每个必要未标记邻接只留一个实例。以下使用[九度归约](../delta9_parallel_reduction.md)已得到的性质：支持阶数 \(n\ge23\)，每个重复束双重且无标记三角形包含重复束，每个重复束的两根有至少 13 个不同根外邻点，并至少有一条未标记根辐条。因此每点额外平行度至多二。

## 标记三角形模板

取任一标记三角形 \(C\)。设 \(Y_i\) 为在 \(C\) 中恰有 \(i\) 个不同宿主邻点的外点，记 \(t=|Y_2|+|Y_3|\)，\(t_3=|Y_3|\)，\(z=|Y_0|\)，并令
\[
 E=27-\sum_{v\in C}d_{G_{\mathrm{s}}}(v).
\]
这里 \(G_{\mathrm{s}}\) 为简单宿主投影。因三角形内部边束皆单份，此 \(E\) 就是前述归约的三根宿主亏损及重复外辐条数之和。式 (3)–(5) 给出 \(z=n-24+E+t+t_3\)、\(9E+2t+10t_3\le20\)。若 \(z>0\)，则 \(t\ge1\)。当 \(E+t_3\ge1\) 时，\(t\le5\)，原式 (5) 对所有 \(1\le r\le7\) 均失败，这部分不依赖 \(n\ge24\)。因此 \(z>0\) 时 \(E=t_3=0\)。原式 (5) 同样独立于 \(n\) 排除 \(3\le t\le8\)，按 \(Y_1\) 与 \(Y_2\) 的标记容量排除 \(9\le t\le10\)。两个双邻点的零点不能超过一个，一个双邻点的零点不能超过两个，证明见原归约。

若 \(z=0\)，则 \(E+t+t_3=24-n\le1\)，也有 \(t_3=0\)。这样，对三角根与同类外点重新编号后得到以下恰好覆盖全部可能的八种参数。

| 支持阶 | 根损耗 | 双邻点漏根 | 零邻点数 | 三组独有邻点数 |
|---:|---|---|---:|---|
| 23 | 根 0 宿主亏一 | 无 | 0 | 6, 7, 7 |
| 23 | 根 0 一条双重辐条 | 无 | 0 | 6, 7, 7 |
| 23 | 无 | 2 | 0 | 6, 6, 7 |
| 23 | 无 | 2, 2 | 1 | 5, 5, 7 |
| 23 | 无 | 1, 2 | 1 | 5, 6, 6 |
| 24 | 无 | 无 | 0 | 7, 7, 7 |
| 24 | 无 | 2 | 1 | 6, 6, 7 |
| 25 | 无 | 2 | 2 | 6, 6, 7 |

最后两行中，唯一双邻点至少一条根辐条未标记。对每一行，任一根外标记边的两端合计至少见两个不同的根点，否则无法见证背向的根标记边。特别地，零邻点只标记到双邻点，任一独有邻点组内部无标记。

## 以八度锐界删点

设八度的无环多重图强团上界为 80。若顶点集 \(T\) 支配宿主的所有九度点，即每个九度点属于 \(T\) 或邻接 \(T\)，则删去 \(T\) 后宿主最大度至多八。剩余标记仍为强团，因为每两条保留标记边的见证只涉及它们的端点。因此至少 18 份标记边接触 \(T\)。单个顶点不可能是这样一个支配集。若 \(|T|=2\)，则两点都必须标记度九，且它们互不宿主邻接，否则共同一条标记边会使删除量至多 17。

对上述任何三角形模板，删去 \(C\cup Y_0\) 后每个剩余点至少失去一份宿主度，所以 \(C\cup Y_0\) 也必须接触至少 18 份标记。若 \(Y_0=\varnothing\)，这强迫至少 15 份外根辐条标记。右边无须对三角形局部的剩余标记是否二部作任何假设。

## 简单支撑中无标记三角形时，蓝边无关联的五环给出锐界

这个归约对任意 \(D\) 成立。假设标记支撑无三角形。取五个顶点形成标记诱导五环，并且五点都没有未标记宿主邻接。不要求这五点各有 \(D\) 份标记。记五环为 \(a_0,\dots,a_4\)，下标按模五。对任一主图点 \(v\)，其在锚五环的宿主邻居均以标记连接，且因标记无三角形，这些邻居是五环的独立集。若仅有一个锚邻点 \(a_i\)，边 \(va_i\) 无法见证边 \(a_{i+2}a_{i+3}\)。若没有锚邻点，任一标记邻点必须在锚五环上形成顶点覆盖，至少需三个锚邻点，同样不可能。这个论证也适用于五环自身的点。

因此所有点唯一分到五组 \(P_i\)，其中 \(P_i\) 点对锚的邻域为 \(\{a_{i-1},a_{i+1}\}\)。若 \(u\in P_i\)、\(v\in P_{i+1}\)，则两条标记边 \(ua_{i-1},va_{i+2}\) 只能由 \(uv\) 见证，故相邻组之间宿主邻接完整。对同组或不相邻两组任意两点，两点共用一个锚邻点，因此二者不能标记相邻。删去所有同组或不相邻组之间的未标记宿主边后，剩下的邻接支撑恰是完全五环膨胀。对于两条不相接的标记边，若所在相邻组对相同或两组对共享一个组，则一个跨组邻接提供见证。若所在组对不交，则五环上这两条边必有一个跨端点的相邻组对，也提供见证。故删边后全部标记仍为强团。此时直接使用[无三角形宿主的奇数度锐界](../无三角形多重图奇数锐界.md)，九度上限为 97。

进一步令 \(B\) 为与未标记边关联的点集，\(U=V(G)\setminus B\)。对任何九度的 98 份标记候选，所有 \(U\) 内宿主边都标记，且因重复束必须有一条未标记根辐条，\(G[U]\) 简单。其不含诱导 \(2K_2\)，否则两条标记无见证。若全局标记图无三角形，则 \(G[U]\) 不能含奇环，因为最短奇环必诱导、长度至少五，长度五已由上段排除，长度七或以上含诱导 \(2K_2\)。因此 \(G[U]\) 是二部图，至多一个非平凡分量，且各侧邻域按包含关系成链。若该分量两侧为 \(A,C\)，且 \(x\in B\) 标记邻接 \(U\) 的一个孤立点 \(y\)，则 \(x\) 到该分量的邻域覆盖分量内所有边（比较 \(xy\) 和分量内的标记）。该邻域又独立，故恰是 \(A\) 或恰是 \(C\)：在连通二部图中，一个独立覆盖对每条边恰选一端，沿路径即得整侧唯一。特别地，若相应侧为 \(A\)，点 \(x\) 除去到 \(A\) 的宿主邻接和至少一份未标记度，至多向 \(U\) 的孤立点贡献 \(8-|A|\) 份标记。

这些归约仅处理九度候选的特定参数和结构。余下结构仍需排除。
