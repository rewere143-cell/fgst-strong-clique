# 最大度九简单图的精确强团界

**定理。** 若有限简单图 \(G\) 的最大度至多九，则 \(\omega(L(G)^2)\le97\)。用五环连续五部大小 \(4,4,5,5,4\) 的完全吹胀取得 97。

若反例存在，取恰好 98 条标记边组成的强团，并把宿主限制在这些边的支持上。保留支持后所有强团见证仍存在。记标记支持阶数为 \(n\)，标记度为 \(h_v\)，全标记三角形数为 \(T\)。由 \(\sum h_v=196\) 得 \(n\ge22\)。[原稿的精确局部缺陷罚项](局部缺陷证书.md) 给
\[
\sum_v h_v(9-h_v)+6T\le156 .
\]
由于 \(h_v\ge1\)，粗略可得 \(9n-196\le156\)，即 \(n\le39\)。再用度数和与该罚项逐整数枚举，得到 \(n\le37\)。枚举由 [现有生成器](odd_fixed_degree_sat.py) 中的度分布递推完成。

| \(n\) | 排除证明 |
|---|---|
| 22 | 只有两种度分布，均有精确 RUP 证明。[固定证书](d9_sat_low) · [原再验报告](d9_partial_verification.json) |
| 23 | 饱和图与未标记度归约，34 个未排除模型均有精确 RUP 证明。[推导](delta9_n23_reduction.md) · [再验报告](d9_n23_verified.json) |
| 24–28 | 先约束标记三角形，再按饱和点结构归约。104 个固定 CNF 和 28 个空分区已经再验。[推导与复现](delta9_n24_n28_reduction.md) · [再验报告](d9_n24_n28_verified.json) |
| 29–31 | 标记图无三角形。使用相同的完整二部或四部路径饱和型，并分别由有理整数界排除或固定 CNF 重放。25 个固定 CNF 和 30 个算术分区都已再次核验。[再验报告](d9_high_verified.json) |
| 32–37 | 按饱和图和外部度容量完全排除，整数枚举覆盖每个许可度分布。[推导与复现](delta9_high_support.md) |

29–31 阶的模板与 24–28 阶相同，只改变支持阶数。除一个分区外，均用每种饱和点数和结构的一份合并公式或空选项排除。唯一拆分的是 \(n=29\)、十一饱和点、完整二部加孤立点的分区。这里仅有两种外点亏损分布，分别给固定公式。独立再验重新生成各 CNF、核对压缩附件展开后的哈希，并重放 8,543,904 条正 RUP 添加行。复现命令如下。

~~~text
python -B d9_verify_high.py --jobs 2 --report d9_high_verified.json
python -B d9_high_support_bound.py
~~~

固定模板中的未决求解日志不参与证明。上表覆盖反例可能的全部支持阶数，因此不存在 98 条标记边的强团。
