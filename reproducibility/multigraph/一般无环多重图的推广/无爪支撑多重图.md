# 无爪简单支撑的无环多重图

设 \(G\) 是有限无环多重图，最大度 \(D\) 按边实例计，标记边 \(H\) 构成强团。若底层简单支撑无诱导的爪 \(K_{1,3}\)，则 \(H\) 满足 Faudree–Gyárfás–Schelp–Tuza 的偶奇精确上界 \(F(D)\)。当 \(D\ge3\)，以下组合计数给 \(m=e(H)\le 6D^2/5+1/4\)。本证明只在一个标记端点对的邻域使用无爪条件。

取含标记实例的根端点对 \(u,v\)，把其全部 \(k\ge1\) 份边标记。记分别只邻接 \(u\)、只邻接 \(v\)、同时邻接两者的根外点集为 \(A_1,A_2,A_3\)，大小 \(x,y,z\)。有 \(x+z,y+z\le D-k\)。令 \(A=A_1\cup A_2\cup A_3\)。所有避开根边束的标记边均有端点在 \(A\)。故
\[
m=k+\sum_{a\in A}d_H(a)-e_H(A)
\le k+D(x+y+z)-e_G(A).
\]
最后一步因为每份 \(A\) 内的未标记宿主边，在度数上界中至少要扣除一单位。

无爪性保证 \(A_1,A_2\) 各自成团，且 \(A_3\) 的简单支撑没有大小三的独立集。对 \(A_3\) 的补图应用 Mantel 定理，得到
\[
e_G(A)\ge \binom{x}{2}+\binom{y}{2}+z^2/4-z/2 .
\]
固定 \(z\)，右侧给出的 \(m\) 上界随 \(x,y\) 增加，故可取 \(x=y=D-k-z\)。展开后得到
\[
m\le D^2+D-k^2 + (D-2k-\tfrac12)z-\tfrac54z^2
\le D^2+D-1 + (D-\tfrac52)^2/5
=\tfrac65D^2+\tfrac14
\]
（\(D\ge3\)）。对偶数 \(D\ge4\)，该式不超过 \(5D^2/4\)。对奇数 \(D\ge11\)，它不超过 \((5D^2-2D+1)/4\)。\(D=9\) 时向下取整为 97。\(D\le7\) 用本阶段的[低度数精确界](../README.md)。

根邻域按独占与共同点划分，沿用 Dębski 与 Śleszyńska–Nowak 对简单图的根边计数。他们在简单图中得到更小的 \(D^2+D/2\) 上界。这里直接扣除宿主内边份数，以处理平行度数。[Dębski–Śleszyńska–Nowak，Theorem 1](https://link.springer.com/article/10.1007/s00373-021-02379-6)
